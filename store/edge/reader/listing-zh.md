## 二、详细描述

读论文时，少切几次标签。

Papilot 把 AI 阅读助手放在浏览器侧边栏：不离开论文页面，就能解释术语、逐句翻译、拿到结构化摘要，并基于当前正文继续追问。

### 划词即用，不打断阅读

选中一段文字，页内直接弹出气泡：**翻译 / 解释 / 存摘录**。结果在气泡里流式出现，不用打开侧边栏，也不用来回切标签。想继续深挖再进侧边栏。

### 整页对照，逐段读

侧边栏「对照」页把正文按段落拆开，逐段翻译成中文，原文与译文上下排列。最多 20 段、每段单独请求，可以随时停止；已译段落缓存在本次会话里，重复阅读不重复计费。

### 摘录本，读完留得下

气泡里的「存摘录」、回答下方的「存摘录」，都会把选中的原文、AI 回答、来源标题与链接存到本机。切到「摘录」页可回看、复制、删除，或一键导出 Markdown 贴进 Obsidian。

### 三个核心动作

- **划词即问**：选中一句，点「解释选中」或「翻译选中」。解释会给出定义、本文语境中的含义与常见误解；翻译逐句对应、保留段落。
- **本页摘要**：一次得到 TL;DR、研究问题、方法、主要结论、局限与可借鉴点，直接贴进笔记。
- **追问本文**：基于当前页正文多轮提问，回答带原文依据，不编造页码与数据。

### PDF 也能读

Edge 内置 PDF 阅读器无法被扩展注入，所以 Papilot 在面板内解析 PDF 全文：点「解析 PDF 全文」，或把下载好的 PDF 直接拖进面板。解析后即可摘要、翻译与追问。

### 术语全篇一致

在设置里维护 `原文 = 译名` 术语表，回答会严格按表翻译；同一篇文章里不会一会儿「嵌入」一会儿「向量」。

### 怎么开始

1. 安装后会自动打开设置页。
2. 选择模型来源：登录 Papilot 账号（按会员额度计费），或填入任意 OpenAI 兼容接口的 Key（数据直连该服务商）。
3. 打开论文详情页，点工具栏的 Papilot 图标。
4. 点「读取本页」，或直接在页面上选中文字。

### 权限与隐私

- 只在你点击动作或发送问题时，才读取当前页正文节选、选中文本与页面标题/URL。
- 只发送到你选择的模型接口；不使用遥测、不读取浏览历史、不申请全站访问权限。
- 登录密码只用于换取令牌，令牌保存在本机；退出登录即清除。
- 详见隐私政策。

### 已知限制

- 整页对照是上下排列的逐段对照，不是左右双栏排版；每次最多 20 段。
- 需要登录账号或自备模型 Key 才能使用 AI 功能。
- 白名单之外的站点，需要在页面上点一次扩展图标授权后读取。
- 扫描版 PDF（无文本层）无法抽取文字。

### 系统要求

Microsoft Edge 116 或更高版本（Chromium 内核）。

## 四、权限理由（逐项填写）

| 权限 | 申请理由 |
|---|---|
| `sidePanel` | 在浏览器侧边栏展示阅读助手界面，与论文页面并排显示。 |
| `storage` | 在本机保存模型配置、术语表与会话记录；不参与账号同步。 |
| `scripting` | 在你点击「读取本页」时，向当前标签页注入脚本以抽取正文。 |
| `activeTab` | 仅在你主动点击扩展时访问当前标签页，不常驻读取。 |
| 学术站点 host permissions | 在 ScienceDirect、Springer、Nature、arXiv、PubMed、CNKI 等论文站点自动捕获划词并读取正文；不包含全站通配。 |
| `https://pp.xinglintools.top/*` | Papilot 账号登录与官方模型网关调用（仅在你选择账号模式时使用）。 |

| 是否使用远程代码 | 否。所有可执行代码均包含在安装包内。 |
| 是否使用遥测/分析 | 否。 |
