# Papilot Edge 扩展 · 试用说明（可直接转发）

> 两个小工具，解决读论文时的两件小事：**看不懂**、**引文格式烦**。
> 试用期 2 周，装完大约 5 分钟能上手。不需要付费，也不会动你的 Zotero 文献库。

## 一、你拿到的是什么

| 扩展 | 作用 | 包 |
|---|---|---|
| Papilot 学术阅读侧边栏 | 在论文页面划词解释、翻译、生成摘要、追问 | `papilot-edge-0.1.0.zip` |
| Papilot 引文快取 | 一键生成 GB/T 7714 / APA / MLA / BibTeX / RIS 引文 | `papilot-cite-0.1.0.zip` |

两个是**独立扩展**，可以只装一个，也可以都装。

## 二、安装（Edge）

1. 把 zip 解压到一个固定文件夹（例如 `D:\PapilotEdge\reader`、`D:\PapilotEdge\cite`），**不要直接双击 zip**。
2. 地址栏打开 `edge://extensions`。
3. 打开左下角（或页面右上角）的「开发人员模式」。
4. 点「加载解压缩的扩展」，选择解压后**包含 `manifest.json` 的那一层文件夹**。
5. 两个扩展重复一次即可。

> 安装后阅读扩展会自动打开设置页；引文扩展无需配置。

## 三、阅读扩展：3 分钟上手

1. **选模型来源**（二选一）：
   - 登录 Papilot 账号：按会员额度计费；
   - 或填自己的 OpenAI 兼容接口：地址 + Key + 模型名。
2. 打开一篇论文，例如 `https://arxiv.org/abs/1706.03762`。
3. 点工具栏的 Papilot 图标打开侧边栏 → 点「读取本页」。
4. 在摘要里选中一句 → 回侧边栏点「解释选中」。
5. 再点「本页摘要」，看四段式结果是否可用。
6. 选中一句话，页内会弹气泡：试「翻译」「解释」「存摘录」。
7. 切到「对照」页，点「翻译本页」，看逐段对照是否顺。
8. 切到「摘录」页，检查刚才存的内容还在。

**PDF 用法**：打开 PDF 后点「解析 PDF 全文」；若提示无法读取，先把 PDF 下载到本地，再拖进侧边栏面板。

## 四、引文扩展：1 分钟上手

1. 打开论文详情页（不是 PDF 阅读器）。
2. 点工具栏的 Papilot 引文图标。
3. 选 GB/T 7714 / APA / MLA / BibTeX / RIS，点「复制引文」。
4. 粘到 Word 或 `.bib` 里检查格式。

## 六、隐私与边界（请放心测试）

- 不会读取你的浏览历史、Cookie 或 Zotero 文献库。
- 只有你点动作时，才会把**当前页正文节选与选中文本**发到你选择的模型接口。
- 引文扩展只读当前页公开书目信息；只有缺字段时才向 Crossref 发一个 DOI。
- 试用包的日志与配置都在你本机；卸载扩展即清除。

## 七、已知限制（不是 bug）

- 首版没有整页双栏对照，只做选区级解释/翻译。
- 扫描版 PDF（没有文字层）无法抽取文字。
- 白名单之外的网站，需要先点一次扩展图标授权。
- 中文库页面若缺少 `citation_*` 标签，引文字段可能不全。
