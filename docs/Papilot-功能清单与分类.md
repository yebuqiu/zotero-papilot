# Papilot 功能清单与分类结构（0.12.0）

> 盘点范围：Papilot 0.11.0 全部用户可见功能（34 项）。
> 分类三原则：**用途**（解决什么问题）→ **场景**（单篇精读 / 批量处理 / 库维护）→ **关联性**（是否共用同一数据流或操作对象）。

---

## 一、分类总览

| # | 类别 | 场景 | 功能数 | 关联性依据 |
|---|------|------|--------|-----------|
| 1 | 阅读助手 | 阅读单篇文献时 | 8 | 全部作用于「当前一篇文献」，产出直接服务阅读理解 |
| 2 | 笔记与卡片 | 读完后沉淀知识 | 4 | 全部以「笔记/卡片文件」为产出物，共用批注数据源 |
| 3 | 批量分析 | 多篇文献横向对比 | 6 | 输入均为 ≥2 篇或整个分类，产出为汇总性笔记/报告 |
| 4 | 库健康 | 文献库元数据与附件维护 | 8 | 全部是对「条目字段/附件」的检查、修复与补全 |
| 5 | 标签与状态 | 组织与筛选 | 5 | 全部读写「标签」这一同一数据维度 |
| 6 | 数据列与配置 | 被动展示 + 全局设置 | 3 | 自动运行的列/侧栏说明 + 全局配置入口 |

---

## 二、逐类功能清单

### 1. 阅读助手（单篇 · AI 精读）
> 场景：打开一篇文献前后。共用链路：`AIChat` 全文提取缓存 + `AIClient`。

| 功能 | 入口（重构前） | 产出 |
|---|---|---|
| AI 工作台（独立窗口） | 工具菜单 | 对话 |
| AI 问答侧栏 | 侧栏（自动） | 对话 |
| 划词浮窗（翻译/解读/追问） | 阅读器（自动） | 浮窗 |
| PDF 速览侧栏 | 侧栏（自动） | 摘要+开篇 |
| AI 总结 | 右键菜单 | 笔记 |
| AI 翻译标题与摘要 | 右键菜单 | 笔记 |
| AI 深度解读 | 右键菜单 | 笔记 |
| 全文对照翻译 | 右键菜单 | 双语笔记 |
| AI 思维导图 | 右键菜单 | 大纲笔记/.md |

注：侧栏与浮窗为自动功能，功能中心内以「说明卡」呈现，不提供运行按钮。

### 2. 笔记与卡片（知识沉淀）
> 关联性：产出物都是笔记或卡片文件；前两项共用 `Annotations.collect` 批注数据源。

| 功能 | 产出 |
|---|---|
| 收集批注为笔记 | 笔记 |
| AI 解读批注 | 笔记 |
| 按模板新建笔记（内置 3 套 + 自定义） | 结构化笔记 |
| AI 制卡导出 Anki | .txt 卡片文件 |

### 3. 批量分析（多篇横向）
> 关联性：输入都是多选/分类；矩阵与综述共用 `matrixMaxItems` 上限与逐篇抽取模式；统计两项共用分类数据源。

| 功能 | 产出 |
|---|---|
| AI 文献矩阵（维度对比表） | 对比笔记 |
| AI 文献综述（带引用编号） | 综述笔记 |
| 引文追溯（参考文献/施引文献） | 笔记 |
| 参考文献一键入库 | 新条目 |
| 分类条目统计 | 弹窗 |
| 文献统计图谱（HTML 报告） | 浏览器报告 |

### 4. 库健康（元数据与附件维护）
> 关联性：都是「检查 → 修复/补全」型维护操作；真假识别与粘贴核验共用同一套 AI 幻觉检测链。

| 功能 | 作用对象 |
|---|---|
| 中文文件名识别元数据 | 标题/作者/期刊/年份 |
| 元数据补全（S2） | 空缺字段 |
| 元数据规范清洗（DOI/日期/标题/URL） | 字段格式 |
| 智能清理（重复/无附件/缺元数据） | 全库扫描 |
| 真假文献识别 | 单条题录 |
| 粘贴文献列表核验 | 外部文本 |
| 开放获取补全文（Unpaywall） | 附件 |
| 附件按规则重命名 | 附件文件名 |

### 5. 标签与状态
> 关联性：全部读写标签维度；阅读状态三态互斥，属同一功能的三档。

| 功能 | 说明 |
|---|---|
| AI 自动打标签 | LLM 建议标签 |
| 规则打标 | 自定义条件规则 |
| 标记为「未读 / 在读 / 已读」 | 互斥三态 + 自动化（新入库→未读，打开 PDF→在读） |

### 6. 数据列与配置
| 功能 | 类型 |
|---|---|
| 期刊分区列（easyScholar+离线） | 自动列 |
| 被引量列（Semantic Scholar，可手动刷新） | 自动列 + 操作 |
| 设置 / 接口连通性测试 / AI 配置快照 | 全局配置 |

## 三、重构后的界面组织（0.12.0）

**一个统一入口：Papilot 功能中心**（独立窗口，单实例）
- 左侧：6 个类别导航（职责单一，一类一页）；
- 右侧：该类别的功能卡片（名称 + 一句话说明 + 运行按钮），顶部搜索框可按名称/说明过滤；
- 头部实时显示主窗口当前选中篇数，提示批量类功能可用性；
- 自动类功能（侧栏/浮窗/数据列）以说明卡呈现，不设运行按钮，避免职责混杂。

**入口收敛**：功能中心置于 工具菜单首位 + 右键 Papilot 子菜单首位；原右键菜单保留作为情境快捷方式（不改变用户既有习惯），自动功能入口不变。

**不变量**：所有功能的核心逻辑（各 `features/` 模块）零改动；功能中心仅做导航与调用分发，经 `Zotero.Papilot` 暴露的模块引用触发现有 `runForSelected()` 等入口。
