# Papilot Edge 伴生扩展 — 候选方案与优先级（2026-10-19）

> 定位：为 Zotero 插件 Papilot 0.56.0 设计一个**只做采集 / 入库 / 阅读、不改库**的 Edge 商店扩展。
> 本文只做调研与产品规划，不含代码；不含 Sci-Hub 及任何绕过付费墙的能力。
> 数据来源区分：**官方文档** = Microsoft Learn / Chromium Docs；**第三方** = chrome-stats / edgecrx / 评测站，数字标注「待核实」。

---

## 0. 一句话结论

Zotero 生态在浏览器侧只剩两个空位：**(1) 官方 Connector 存不进去的页面**（中文库、机构库、预印本详情页），**(2) 存进去之后没人管的"读"**（翻译/术语/摘要/引文核对）。
前者价值最高但合规与维护成本最高，后者可以直接把 Papilot 的 AI 能力搬到浏览器、复用自建账号与网关、且**不依赖 Zotero 桌面端即可通过审核测试**。
**首版只上 1 个：学术阅读侧边栏（B）。**

## 1. 背景与硬边界

### 1.1 可直接复用的 Papilot 资产

| 模块 | 规模 | 对扩展的可用性 |
|---|---|---|
| arXiv 工具包 | 2,278 行 | 高（纯 HTTP + 解析，可整体搬） |
| 翻译引擎 `ai/translate.js` | 1,940 行（13 家引擎） | 高（去掉 Zotero prefs 读配置即可） |
| 参考文献格式 `features/ref-format.js` | 1,198 行 | 中（部分依赖 Zotero CSL 运行时，需替换为 citeproc-js） |
| 多源检索 `features/ref-sources.js` | 1,039 行 | 中高（Crossref/OpenAlex 类调用可复用） |
| 账号 `ai/account.js` + `ai/client.js` | 1,088 行 + | 高（换成 `chrome.storage` 存 token，网关域名不变） |
| WebDAV `core/webdav.js` | 702 行 | 低（浏览器侧 CORS 与凭据风险大，不建议） |
| 20 个 XHTML 页面（XUL `<window>`） | 3,273 行 | **不可复用**（XUL ≠ HTML，需重写） |

结论：**能搬的是「逻辑层」（约 6,000–7,000 行），不能搬的是「界面层」**。任何方案都要重写 UI，估工时不能按"界面也有了"算。

### 1.2 Zotero 联动硬边界（决定产品天花板）

| 通道 | 能力 | 限制 | 需要用户做什么 |
|---|---|---|---|
| 本地 API `127.0.0.1:23119/api/` | **读**条目/集合/标签/全文/BibTeX/CSL-JSON | 只读；POST/PUT/PATCH/DELETE 返回 501；Zotero 7+ 默认关闭 | 手动开 `extensions.zotero.httpServer.localAPI.enabled` |
| `POST /connector/saveItems` | **只新增**条目 | 不支持更新/删除/移动/建集合；**不去重** | Zotero 桌面端运行 |
| `POST /connector/saveAttachment` | 建条目 + 传 PDF 字节流（二步协议） | 同上 | 同上 |
| `POST /connector/import?session=` | BibTeX/RIS 批量导入 | 同上，仍是"新增" | 同上 |
| `GET /connector/ping` | 探活 | — | 同上 |

**硬边界一句话：扩展做不了"改元数据、整理分类、批量维护"。凡是需要动已有条目的想法，直接砍掉，不要设计。**

### 1.3 Edge 平台事实

| 项 | 结论 | 来源 |
|---|---|---|
| 开发者账号 | Partner Center 注册 Microsoft Edge program，**免费**，个人/企业均可 | 官方 |
| 审核时长 | 官方口径**最长 7 个工作日**；声明远程代码会额外延长 | 官方 |
| 清单版本 | **仅 MV3**（2022-07 起不收新 MV2；2026-08 起对存量发弃用提示） | 官方 |
| 隐私页必填五项 | Single Purpose / 权限逐项说明 / 是否远程代码 / 数据用途声明 / 隐私政策 URL | 官方（2026-05 起全量） |
| 单一用途 | 必须"清晰、狭窄、明确"，模糊描述会被打回 | 官方 Developer Policy 1.1.1 |
| 可测试性 | 必须"完全可测试"，需提供测试账号/步骤；服务端必须可用 | 官方 Developer Policy 1.3 |
| 侧边栏 `sidePanel` | Chromium 侧 **Chrome 114+ / MV3**，需 `sidePanel` 权限；`sidePanel.open()` 需 116+ | Chromium 官方 |
| 企业批量部署 | `ExtensionInstallForcelist` 静默安装、用户不可卸载；**未加 AD 域的 Windows，强制安装仅限 Edge Add-ons 商店已上架扩展** | 官方 |
| 国内可达性 | Edge Add-ons 商店国内可直接访问；Chrome Web Store 需额外网络条件 | 第三方多源一致 |
| 商店体量 | 约 1.2 万+ 扩展（**待核实**） | 第三方博客 |

**为什么还是要在 Edge 商店上架**（既然 Edge 也能装 Chrome 商店）：
1. 企业/高校策略里"只允许 Edge Add-ons"是常见配置，不上架就无法被强制部署；
2. 商店内搜索与推荐位是唯一的自然流量入口；
3. 国内用户不翻墙可达。
**代价**：Edge 侧是独立 extension id，OAuth 回调、`externally_connectable` 白名单、服务端 allow-list 都要加一份。

| Scholarcy | —（Chrome 侧约 8 万，4.0/39） | 中 | 免费每天 1–5 篇、$9.99/月、仅摘要不联动库 | 学术摘要需求真实存在且付费意愿成立 |

## 3. 候选方案（7 个）

### A. Papilot 中文文献题录补全（CN Scholar Capture）

| 项 | 内容 |
|---|---|
| 核心功能 | ①在知网/万方/维普/百度学术详情页点一下，抓取**页面上用户可见**的题录字段；②补全官方 translator 常丢的字段（作者机构、基金、中图分类号、学位授予单位/导师）；③入库前字段预检表（红/黄/绿），用户确认后写入；④可选同时下载该页 PDF 附件 |
| 痛点场景 | 研究生下载 50 篇知网 PDF，拖进 Zotero 全是文件名当标题；装茉莉花要折腾 xpi + 手动更新翻译器 + 重启两次 |
| 与 Zotero 交互 | 写：`saveItems` + 可选 `saveAttachment`（二步协议）；**需 Zotero 运行**；**不需开本地 API**。降级：Zotero 未运行时导出 RIS/BibTeX 文件 |
| 差异于官方 Connector | 官方 translator 由社区维护、发版滞后且只能靠 Zotero 自更新；扩展可**独立按天发版**修选择器，且能做字段级预检与人工确认，不把脏数据直接写进库 |
| 开发价值 | 复用：`ref-sources.js` + 中文文献模块 ≈ 1,000–1,500 行可用；工时 **3–4 人周**（单站点单形态 MVP）；风险：**高**（知网 ToS、DOM 周更、可能被判"协助抓取"）；变现：会员专属，最容易被付费 |
| 优先级 | **P1**（技术最痛，但合规与维护成本最高，先不大投入） |

### B. Papilot 学术阅读侧边栏（Academic Side Reader）

| 项 | 内容 |
|---|---|
| 核心功能 | ①划词：解释概念/译成中文/查术语（走 Papilot 术语库）；②整页或 PDF 选区：段落级双语对照、本文摘要与创新点提取；③"追问本文"：基于当前页正文的多轮问答；④结果一键复制 / 导出 Markdown |
| 痛点场景 | 读英文 PDF 时要在浏览器、翻译插件、ChatGPT 之间来回贴；术语前后译法不一致（同一篇里 "embedding" 一会儿"嵌入"一会儿"向量"）；读完想留点东西只能手抄 |
| 与 Zotero 交互 | **不交互**（纯浏览器侧）；不需 Zotero 运行、不需本地 API。降级：AI 不可用时退化为纯本地词典/复制 |
| 差异于官方 Connector | 官方只负责"存进去"，存完的阅读环节完全空白；沉浸式翻译/Sider 是通用工具，没有学术术语库、不认 Papilot 的 13 家引擎与自有网关 |
| 开发价值 | 复用：`ai/translate.js` 1,940 行 + `ai/account.js`/`client.js` ≈ 2,500 行可移植；工时 **4–6 人周**；风险：**中**（隐私披露 + 权限收敛 + 生成式 AI 合规）；变现：**最强**（直接接 pp.xinglintools.top 会员与官方 AI 网关，可做每日免费额度） |
| 优先级 | **P0** |

### C. Papilot 开放获取全文直达（OA Finder）

| 项 | 内容 |
|---|---|
| 核心功能 | ①在任意文献详情页，检查是否存在**合法 OA 副本**（Unpaywall / OpenAlex / PMC / arXiv / 作者主页）；②展示"有没有、在哪、什么许可"；③一键取 PDF 并 `saveAttachment` 挂到条目；④没有 OA 时明确写"请走机构订阅"，不做替代方案 |
| 痛点场景 | 在 PubMed 看到一篇，Zotero 只存了元数据没附件；手动去 Unpaywall 查、下载、再拖进 Zotero，一步三跳 |
| 与 Zotero 交互 | 读：可选本地 API `/api/` 查该条目是否已有附件（未开则跳过）；写：`saveAttachment`；**需 Zotero 运行**；本地 API **可选**。降级：直接下载到浏览器下载目录 + 提示拖入 Zotero |
| 差异于官方 Connector | 官方只在页面自带 PDF 链接时才存附件，**从不主动查 OA 副本**；也不告诉用户"这篇到底能不能合法拿到" |
| 开发价值 | 复用：`ref-sources.js` 1,039 行 ≈ 700 行可用；工时 **3 人周**；风险：**低**（只碰 OA 源）；变现：免费引流，批量/订阅归会员 |
| 优先级 | **P1** |

### D. Papilot arXiv 预印本雷达（arXiv Radar）

| 项 | 内容 |
|---|---|
| 核心功能 | ①按关键词/作者/分类建订阅；②每日/每周新论文清单（侧边栏或弹窗）；③勾选后批量 `saveItems` 或 `import?session=`（BibTeX）；④标注"已在你库里"（需本地 API，可选） |
| 痛点场景 | 追一个方向要每天手动刷 arXiv 列表，看到相关的再一篇篇点 Connector |
| 与 Zotero 交互 | 写：`import?session=` 批量导入；**需 Zotero 运行**；本地 API 可选。降级：导出 BibTeX 文件 |
| 差异于官方 Connector | 官方是"你在页面上、它存这一页"；**没有订阅、没有清单、没有批量** |
| 开发价值 | 复用：arXiv 工具包 2,278 行，**复用度最高**；工时 **2–3 人周**；风险：低（arXiv 允许合规 API 访问，需遵守其速率要求）；变现：弱（arXiv 用户付费意愿低，可作免费引流） |
| 优先级 | **P2** |

### E. Papilot 参考文献格式快取（Cite Grabber）

| 项 | 内容 |
|---|---|
| 核心功能 | ①在期刊页/Google Scholar/百度学术/PubMed 一键取引文；②**当场**渲染成 GB/T 7714-2015、APA 7、MLA、BibTeX、RIS 五种；③单击复制纯文本或富文本（可直接粘进 Word）；④可选"存进 Zotero" |
| 痛点场景 | 写综述时要往 Word 里塞一条 GB/T 7714 格式的参考文献，得回 Zotero → 右键 → 导出 → 选格式 → 打开文件 → 复制，五次点击 |
| 与 Zotero 交互 | 默认**不交互**（纯本地格式化）；勾选入库时用 `saveItems`；需 Zotero 运行**仅为可选的入库动作**。降级：无 Zotero 时仅复制，完全可用 |
| 差异于官方 Connector | 官方把数据搬进库，**不在写作现场产出成品文本**；格式转换必须回到 Zotero 或 Word 插件 |
| 开发价值 | 复用：`ref-format.js` 1,198 行（需把 CSL 运行时换成 citeproc-js）≈ 800 行可用；工时 **2 人周**；风险：**最低**（纯本地计算、无数据外传、权限极少）；变现：弱，但**审核通过率最高**，适合当"第二个扩展"或引流钩子 |
| 优先级 | **P1** |

### F. Papilot 库健康只读看板（Library Health Lite）

| 项 | 内容 |
|---|---|
| 核心功能 | ①只读扫描本地库：重复条目、缺 DOI、缺 PDF、元数据残缺；②按集合/年份/期刊分布；③生成"待处理清单"导出 CSV，用户在 Zotero 里自己动手 |
| 痛点场景 | 库到 2,000 条后不知道哪些是脏数据，桌面版库健康必须开 Zotero 全屏看 |
| 与 Zotero 交互 | **只读** `/api/`；需 Zotero 运行 **且必须开本地 API**（默认关闭，这是最大门槛）；降级：无降级，功能整体不可用 |
| 差异于官方 Connector | 官方不做库分析；Papilot 桌面版有，但扩展能在侧边栏常驻、跨窗口 |
| 开发价值 | 复用：库健康逻辑与 Zotero API 深度耦合，仅约 400–600 行可搬；工时 **3 人周**；风险：中（需为 `127.0.0.1` 申请 host 权限，审核需解释清楚"只读本地"）；变现：弱 |
| 优先级 | **P2** |

### G. Papilot 引文核查与撤稿预警（Citation Checker）

| 项 | 内容 |
|---|---|
| 核心功能 | ①在任意含参考文献列表的页面（预印本、综述、导师给的 Word 转网页、投稿模板）抽取引文；②逐条查 Crossref/OpenAlex 校验是否存在、DOI 是否对得上；③交叉 Retraction Watch 标出**已撤稿**；④输出"问题清单"，不自动改文 |
| 痛点场景 | 综述里引的一条文献其实已被撤稿；导师给的参考文献列表里 DOI 是错的，投稿被编辑指出 |
| 与 Zotero 交互 | **不交互**（只查公开元数据）；不需 Zotero、不需本地 API；降级：无网络时仅做本地格式解析 |
| 差异于官方 Connector | 官方只关心"能不能存进来"，**从不校验真假**；这是 Zotero 生态完全空白的一块 |
| 开发价值 | 复用：`ref-sources.js` 的 Crossref/OpenAlex 调用 ≈ 500 行；工时 **3–4 人周**；风险：低（只读公开 API，无用户数据外传）；变现：中（科研诚信场景 B 端/机构愿意付费，但 C 端使用频率低） |
| 优先级 | **P2**（差异化最高，但低频） |

## 4. 打分矩阵

**权重与理由**

| 维度 | 权重 | 为什么是这个权重 |
|---|---|---|
| 用户价值 | 30% | 单一用途扩展只有"高频真痛"才活得下来；低频功能装机即沉默 |
| 差异化 | 20% | 官方 Connector 510 万装机、沉浸式翻译 380 万，正面竞争没有胜算，必须找缝 |
| 技术可行性 | 20% | 团队主线是 Zotero 插件，第二战场不能是高维护量的坑 |
| 审核合规风险 | 15% | 一次被拒 = 1–7 工作日 + 品牌损耗；知网相关还有版权风险；此项分高 = 风险低 |
| 代码复用度 | 15% | 决定首版能否在 4–6 周内出；但复用高不等于值得做，故不给更高权重 |

**评分（1–5，审核合规项 5 = 风险最低）**

| 方案 | 用户价值 30% | 差异化 20% | 技术可行 20% | 审核合规 15% | 代码复用 15% | 加权总分 | 排名 |
|---|---|---|---|---|---|---|---|
| **B 学术阅读侧边栏** | 5 | 3 | 5 | 4 | 4 | **4.30** | 1 |
| **E 参考文献格式快取** | 4 | 3 | 5 | 5 | 4 | **4.15** | 2 |
| **G 引文核查与撤稿预警** | 3 | 5 | 4 | 5 | 4 | **4.05** | 3 |
| **C 开放获取全文直达** | 4 | 4 | 4 | 4 | 4 | **4.00** | 4 |
| **A 中文文献题录补全** | 5 | 5 | 3 | 2 | 3 | **3.85** | 5 |
| **D arXiv 预印本雷达** | 3 | 3 | 5 | 4 | 5 | **3.85** | 5 |
| **F 库健康只读看板** | 3 | 3 | 4 | 4 | 3 | **3.35** | 7 |

> 说明：A 的用户价值与差异化都是满分，被"技术可行性 3 + 合规 2"拉下来。这是**有意为之的保守评分**——如果团队愿意把知网维护当长期成本承担，A 可以上抬到 P0 第二功能。

## 5. Top 3 详述

### Top 1 — B：Papilot 学术阅读侧边栏（P0）

**用户故事**
1. 作为在读博士生，我在 ScienceDirect 打开一篇 30 页 PDF，想边读边把不认识的术语和图注搞清楚，不要切标签页。
2. 作为非英语母语研究者，我要段落级双语对照，并且同一篇文章里 "ablation" 必须始终译成"消融"。
3. 作为要写综述的人，我读完想拿到"研究对象/方法/结论/局限"四段式卡片，贴进 Obsidian。

**MVP 范围（首版）**

| 做 | 不做 |
|---|---|
| 侧边栏 UI（`sidePanel`，仅学术域名白名单注入） | Zotero 联动（不入库、不读库） |
| 划词：解释 / 翻译 / 术语 | 笔记写回 Zotero |
| 整页或选中段落：双语对照 + 摘要 | 图像生成、YouTube 字幕、多模型并排对比 |
| 术语库（复用 Papilot 术语表） | 自定义 prompt 市场、社区分享 |
| 结果复制 / 导出 Markdown | PDF 全文重排翻译（沉浸式翻译已做得很好，不碰） |
| 每日免费额度 + 账号登录 | 团队协作、云端历史 |

**权限策略（直接决定审核时长）**：`sidePanel` + `storage` + `activeTab` + `scripting`，host 权限走 **`optional_host_permissions` 按需申请** + 内置学术域名白名单（`*.sciencedirect.com`、`*.springer.com`、`*.arxiv.org`、`*.ncbi.nlm.nih.gov`、`*.cnki.net` 等），**不申请 `<all_urls>`**。

**与 Papilot 账号 / 会员的关系**：直接复用 `ai/account.js` + `ai/client.js` → 登录 pp.xinglintools.top 同一套账号；免费档 = 每日 N 次（走官方 AI 网关），付费档 = 无限 + 术语库 + 长文档；同时支持"自带 Key"（用户填自己的 DeepSeek/OpenAI Key，不消耗额度）——这条能显著降低审核对"付费功能可测试性"的质疑。

### Top 2 — E：参考文献格式快取（P1）

**用户故事**：作为要交初稿的硕士生，我一边看 PDF 一边在 Word 里写，需要一条 GB/T 7714 格式的参考文献，最好一次点完就粘上。

**MVP 范围**：只做"读当前页引文 → 渲染 GB/T 7714-2015 / APA 7 / MLA 9 / BibTeX / RIS → 一键复制"。
**不做**：Zotero 入库、批量、自定义 CSL 编辑器、文献去重、Word 插件。
**与账号体系**：完全本地、免费、无需登录——它的定位是**零门槛钩子**，侧边栏里放一行"用 Papilot 管理这篇文献"的引导。

### Top 3 — G：引文核查与撤稿预警（P2）

**用户故事**：作为投稿前的研究者，我把综述的参考文献列表过一遍，想知道哪条根本不存在、哪条 DOI 是错的、哪条已经撤稿。

**MVP 范围**：只做"抽取 → Crossref/OpenAlex 校验 → Retraction Watch 比对 → 出问题清单（可导出 CSV）"。
**不做**：自动改写引文、自动替换 DOI、批量整库核查。
**与账号体系**：免费单篇核查引流；"整库核查 / 定期巡检 / 机构报告"归会员或 B 端授权。

## 6. 首版建议：只上 1 个

**首版只上 B，理由按重要性排序：**

1. **审核可测试性是硬门槛。** Edge Developer Policy 1.3 要求"扩展必须完全可测试"。A / C / D / F 都依赖 **Zotero 桌面端运行**——审核员不会为一个扩展去装 Zotero、建测试库、开本地 API。B 不依赖外部软件，审核员装上就能测，这是**通过率的决定性差异**。
2. **单一用途最容易说清。** B 的 Single Purpose 可以写成一句话："在学术论文页面上提供 AI 阅读辅助（术语解释、双语对照、段落摘要）。" A 会被追问"你到底算抓取工具还是文献管理工具"，G 要被追问"你和文献管理什么关系"。
3. **只有 B 能自然接会员。** A/E/G 要么免费要么 B 端，只有 B 的每一次调用都消耗 AI 成本、都能对应到余额/会员，才是 Papilot 账号体系在浏览器侧的真实出口。
4. **B 是唯一不碰版权风险的。** 处理"用户已合法打开的页面内容"与"帮用户从知网批量搬运"是两种完全不同的法律姿势。

**第二功能（第二支扩展，不要塞进 B）**：优先 **E**（零风险、2 人周、可作为免费钩子）；若首版侧边栏的学术用户留存数据好，再上 **C**（把"读"和"拿到全文"闭环）。
**明确不建议把 E / C 塞进 B 同一个扩展**——单一用途审核下，"AI 阅读 + 引文格式化 + 全文下载"三条并列会被直接判为多功能而打回。

## 7. 明确不做清单

| 不做 | 原因 |
|---|---|
| Sci-Hub / LibGen / 任何绕过付费墙的全文获取 | 法律风险，商店政策 2.8/2.9 直接命中 |

| 逆向机构代理登录、复用校园网 Cookie 池 | 违反机构与数据库 ToS |
| 论文代写 / AIGC 洗稿 / 降重 / 生成综述正文 | 学术不端，商店政策 1.1.3 与品牌风险 |
