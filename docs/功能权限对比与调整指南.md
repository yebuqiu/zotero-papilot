# 功能权限对比与调整指南

> 依据：`server/lib/membership.js`、`server/lib/balance.js`、`server/account-server.js`（网关校验链）、
> `server/data/{membership,channels,pricing}.json` 生产配置、`chrome/content/scripts/ai/account.js`、
> `chrome/content/prefs-account.js`（插件端门控）。
> 本文回答三件事：**谁能用什么 / 为什么这样分 / 想改去哪改**。

---

## 0. 一句话架构

**功能永久免费，算力按量付费。** 付费墙只存在于「官方 AI 网关」一个域内，且只管两件事：
**能选哪些模型**（分层）和**能用多少**（次数/余额）。插件本体全部功能对所有人（含未登录）开放。

```
插件功能（分区列/标签治理/PDF对比/翻译/问答/批量分析/MCP…）
   │  全部免费 —— 本地运行，无服务器成本
   ▼
AI 能力消费 ──┬── 走自己的 Key（自定义通道）──► 永不限制、不计量（服务端管不到）
              └── 走官方网关（需登录）──► 四层校验：
                    ① 活动通道(503) → ② 上线清单 publishedModels(400)
                    → ③ 套餐模型分级 highTierModels(403 MODEL_REQUIRES_PRO)
                    → ④ 余额 precheck（402 INSUFFICIENT_BALANCE / BALANCE_REQUIRED_FOR_HIGH_TIER）
                       ★ 1.8.0 起没有「每日次数」这一层（dailyLimit 已取消）
```

## 1. 权限对比总表

### 1.1 两者共用（所有人可用，无需登录、无需付费）

| 功能 | 说明 |
|---|---|
| 期刊分区列（中科院/JCR） | 列本身 + 内置数据集 + 自定义 JSON 免费；**在线查询（easyScholar）见下表** |
| 标签治理 / 标签状态 | 纯本地库操作 |
| 附件体检（库健康） | 本地扫描 |
| 检索发现（arXiv 两阶段检索等） | 直连 arXiv 等公共 API，成本为零 |
| 笔记卡片、数据列 | 本地功能 |
| PDF 分区对比 / 双栏对照 / 左原右译 | 本地渲染 + 官方 AI 计量（AI 部分走下表） |
| 多引擎翻译（13 引擎） | 自带免密钥引擎或用户自己的 Key |
| 参考文献一键入库（五源联合检索） | 公共 API + 可选 AI 补空 |
| AI 问答悬浮窗、划词、批量分析 | **功能入口免费**；其中 AI 调用按所选通道计 |
| MCP 互操作 | 本地服务 |
| 自定义模型通道（自带 Key） | **永不限制、不限数量、不计额度** |

**理由**：这些功能全部在用户本机运行，服务器零成本；锁功能违背「插件本体永久免费开源（Apache-2.0）」
的产品定位，只会伤害口碑与装机量。AI 类功能里真正花钱的只有官方网关的 token 成本，已单独设阀门。

### 1.2 Free（免费注册登录）可用

| 权益 | 当前值 | 代码/配置锚点 |
|---|---|---|
| 官方网关 auto 模型 | 恒免费，**即使被误配进付费清单也免费** | `account-server.js modelsForUser()`；守卫断言 `test/ai-tier.test.js:328` |
| 可用官方模型 | **auto + `deepseek-v4-flash`**（2 个基础档，2026-10-14 起） | `channels.json highTierModels` 反选 |
| 每日调用次数上限 | **无**（1.8.0 起取消「赠送调用次数」，不再有每日次数） | — |
| 注册赠送余额 | ¥6，30 天有效，**仅基础模型可用** | `pricing.json balance.signupGrantMicro / signupValidDays` |
| 新用户全模型试用 | 7 天（现场算，不落盘） | `membership.json ai.trialDays`（0=关） |
| 在线分区查询（easyScholar） | **须自带 Key**（easyscholar.cn 免费注册）；未登录亦不例外。1.9.0 起可把 Key 托管到自己账号（AES-256-GCM 加密，换机自动取回），Free 与 Pro 同权 | `rank-column.js esKey()`；`/api/user/secrets` |
| 价格表可见、下单、激活码激活 | 与 Pro 同一套入口 | 订单/激活路由对全体登录用户开放 |

**理由**：注册登录已经是筛选（有会话可计量、可限速）；Free 的定位是「个人日常够用」——
auto 是成本最低的兜底模型，注册赠送 ¥6 覆盖新用户的日常试用，既让免费用户留存，又把高频/重模型
需求的用户推向 Pro。用尽后由余额拦截（402），可自带 Key 或充值继续。

### 1.3 Pro（付费）专属

| 权益 | 当前值 | 代码/配置锚点 |
|---|---|---|
| 账号与密钥中心（个人中心） | 0.66.0 起：第三方凭据集中管理（0.67.0 扩到 **8 类**：知网账号+密码 / 坚果云 / 期刊分区 / 自定义 AI Key / 第三方文献源 / Semantic Scholar / MCP 令牌 / 旧版单通道 Key）——默认脱敏、按需解锁、可设访问口令与自动隐藏、**逐项「仅托管」**（本机不留明文）、加密托管到本人账号、本地访问审计。Free 打开为锁定卡（列出能力、价格与升级入口，不渲染任何值） | `cred-vault.js` + `vault.xhtml`；`Zotero.Papilot.credVault`；`docs/账号与密钥中心-0.67.0.md` |
| 高级模型清单 | `channels.json.highTierModels`（生产当前 = 上线 6 档中除 `deepseek-v4-flash` 外的 **5 档**，详见 §3） | `account-server.js highTierModels() / highTierAccess()` |
| 每日调用次数上限 | **无**（1.8.0 起取消；余额是唯一阀门） | — |
| 每月订阅额度 | **¥8/月**（微元 8000000，**当期不结转**；2026-10-27 由 ¥20 下调，见 §3⑤）。**后台可配**：会员管理 → 「Pro 会员每月赠送额度」卡片，范围 0～1000 元、最多两位小数，0 = 停止赠送 | `membership.json plans.Pro.monthlyGrantMicro` |
| 高级模型可吃余额 | 高级模型只从「订阅额度 + 充值余额」扣，跳过注册赠送 | `balance.js payableMicro()/consume()` |
| 邮件优先支持 | 服务承诺（无代码强制） | `plans.Pro.features` 文案 |
| 在线分区查询（easyScholar） | **无内置 Key**：0.56.0 已移除（提交 `bc00aa3`，第三方 Key 无转售授权）；Pro 与 Free 一致，均须自备（可托管到账号，1.9.0） | `rank-column.js esKey()`；无官方 Key / 服务端代理 |

**理由**：高级模型（推理档/长上下文）是**唯一真实成本项**——上游 token 单价高，按量计费后
必须有人买单；每月 ¥8 额度（后台可调）按「高频写论文/综述」的使用频率校准；试用 7 天是
转化漏斗（先尝到全模型再决定）。

### 1.4 充值余额（与套餐正交，Free/Pro 均可充值）

| 权益 | 当前值 | 锚点 |
|---|---|---|
| 充值档位 | ¥10 / ¥30→¥33 / ¥100→¥115 | `pricing.json balance.rechargeOptions` |
| 充值余额 | **永不过期**，全模型可用（含高级模型） | `user.balance.paidMicro` |
| 余额强制开关 | `enforce=false`（观察模式：只记账不拦截） | `pricing.json balance.enforce` |

**理由**：充值解决「不想订阅但偶尔要用强模型」的场景；paidMicro 永不过期是信任基础。
扣减顺序：**注册赠送 → 订阅额度 → 充值**（越保值越晚扣）。

## 2. 每项划分理由速查

| 划分 | 决定因素 |
|---|---|
| 功能全免费 | 本地运行零成本 + 开源定位 + 装机量是转化漏斗入口 |
| 官方网关才收费 | 唯一有真金白银成本的地方（上游 token） |
| auto 恒免费 | 兜底入口，一次误配锁死全部免费用户（有专门断言守卫） |
| 自带 Key 永不限 | 无成本、管不到，还是「可接入自己接口」的卖点 |
| 模型分免费/付费档 | 推理档/长上下文 token 成本高数倍；基础档成本低可负担 |
| 次数限额 Free 100 / Pro 3000 | 防薅上游 Key（网关另有每 IP 每分钟全局限速）；按使用频率分级 |
| 试用 7 天 | 让新用户体验全模型后自然转化；`createdAt` 现场算，零迁移 |
| 注册赠送限基础模型 | 赠送是拉新补贴，不该补贴最贵的模型 |
| 订阅额度不结转 | 控制成本敞口；防囤额度 |
| 「多通道一键切换」「邮件优先支持」 | **纯文案权益，无代码强制**（自定义通道 Free 也不限数量） |

  年付满额使用仍保留运营毛利；已按 ¥20 发放过的当期额度不回收。
- **配置入口独立成卡片**：会员管理 →「Pro 会员每月赠送额度」（`#pro-grant-card`）——展示当前额度、

  卡片只提交 `plans.Pro.monthlyGrantMicro`，不会带上大表单里其它未保存的编辑。
- **校验（服务端 `validateMonthlyGrantMicro` 为唯一口径，后台表单同规则前置提示）**：
  必须是数字或非空数字字符串；`0 ≤ 值 ≤ 1000 元`（微元 1e9）；`0` = 停止赠送；
  空串 / null / 布尔 / 数组一律 400 拒绝（`Number('')`、`Number(null)` 都是 0，
  不拦会把「没填」静默变成「停发」）。非法提交不落库、不产生快照、不改变当前额度。

  已发放的当期额度不会被追改。
- **设置界面同步**：`GET /api/plans` 的 `proMonthlyGrant.amountMicro` 由同一配置派生，
  插件对比表（`#pp-cmp-grant-pro`）与登录提示据此渲染；「全部刷新」会强制重拉套餐目录。

**⑥ 历史记录（已过时）**：2026-10-14 曾把 Pro 月额度 ¥20 → ¥10（消除「付 ¥9.9 得 ¥20」倒挂），

### 4.3 硬约束（改层级前必读，均有断言/守卫）

1. **`auto` 恒免费**：不许通过任何配置把它变成付费——守卫在 `test/ai-tier.test.js:328`
   （故意把 auto 误配进高级清单仍须免费）；`admin-e2e.test.js:625` 亦有 E2E。
2. **自带 Key 通道永不限制**：不经本站、无成本；限制了只拦老实用户。
3. **越权调高级模型必须 403 `MODEL_REQUIRES_PRO` 且文案含两份清单**（当前可用/升级后可用），
   **不静默换便宜模型**；插件端对应「可见地回落 auto 并写明原因」。
4. **旧服务端兼容**：插件 `aiTier()` 对无 `ai` 块的旧服务端按「不限制」处理且绝不缩小用户当前选择。
5. 配置改动走管理页或 API（`server/data/*.json` 会被服务端内存副本 `save()` 覆盖，不可手改文件）；
   改完**同轮重启生产 :8000** 并核对 `/api/health`。
6. 改任何门控后跑 `python scripts/preflight.py --fast`，模型分级相关另跑 `node test/ai-tier.test.js`。
