## 一、安装与更新

### 安装

1. 下载安装包 `papilot-x.y.z.xpi`：
   - Gitee 发行版：https://gitee.com/cassiuschen9261/zotero-papilot/releases
   - 或直链（最新稳定版）：`https://gitee.com/cassiuschen9261/zotero-papilot/raw/main/dist/papilot-0.13.1.xpi`
2. 打开 Zotero → **工具** → **插件**（Plugins）
3. 点右上角**齿轮** → **Install Plugin From File…** → 选中 xpi 文件
4. 按提示重启 Zotero，菜单栏「工具」里出现 Papilot 系列条目即安装成功

### 更新

已内置自动更新：Zotero 定期检查新版本，有更新时插件页会出现升级提示，点一下即可，无需重装。
也可随时手动下载新 xpi 覆盖安装（设置和数据都保留）。

## 二、AI 大模型接入（核心配置）

所有 AI 功能（问答、翻译、解读、综述、打标、制卡……）共用一套 AI 配置。
入口：**编辑 → 设置（Settings）→ Papilot**

### 方式一：自动探测（推荐，最省事）

1. 在 **API Key** 框粘贴你的密钥
2. 点 **「自动探测服务商」**——插件会并发请求各主流服务商的 `/models` 接口，自动识别你的 Key 属于哪家，并拉取可用模型列表
3. 从**模型下拉**中选择模型（或直接手填任意模型名）
4. 点 **「测试连接」**，显示 ✓ 即配置成功

支持自动探测的服务商：DeepSeek、通义千问（阿里云百炼）、Kimi（月之暗面）、智谱 GLM、SiliconFlow、OpenAI 等——一切 **OpenAI 兼容接口**（`/v1/chat/completions`）都行。

### 方式二：手动配置

| 字段 | 说明 | 示例 |
|---|---|---|
| API Key | 服务商控制台创建的密钥，`sk-` 开头 | `sk-xxxxxxxx` |
| 服务商 | 下拉选择；选「自定义」时 Base URL 自己填 | DeepSeek |
| Base URL | API 地址（自定义/本地网关时填） | `https://api.deepseek.com/v1` |
| 模型 | 下拉选择或手填 | `deepseek-chat` |

### 方式三：本地大模型 / 自建网关

隐私敏感或想零成本跑本地模型（Ollama、LM Studio、vLLM、one-api/new-api 网关等）：

1. 本地起好服务，确认浏览器访问 `http://127.0.0.1:端口/v1/models` 能返回模型列表
2. Base URL 填 `http://127.0.0.1:端口/v1`
3. API Key：多数本地服务不校验，随便填一串（如 `sk-local`）即可；网关类按实际 Key 填
4. 模型名填本地服务的模型 ID

### 各厂商 Key 申请地址（快捷参考）

| 服务商 | 控制台 | Base URL |
|---|---|---|
| DeepSeek | platform.deepseek.com | `https://api.deepseek.com/v1` |
| 通义千问 | bailian.console.aliyun.com | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Kimi | platform.moonshot.cn | `https://api.moonshot.cn/v1` |
| 智谱 GLM | open.bigmodel.cn | `https://open.bigmodel.cn/api/paas/v4` |
| SiliconFlow | cloud.siliconflow.cn | `https://api.siliconflow.cn/v1` |

### 进阶设置

- **温度（0-2）**：越低越稳定，翻译/总结建议 0.2-0.4；头脑风暴可调高
- **最大输出 tokens**：长文翻译建议 ≥ 4096
- **System Prompt**：AI 的全局人设，可自定义（默认中文回答 + Markdown 输出）
- **全文最大字符数**：送入 AI 的 PDF 全文截断上限（默认 16000，长文献精读可调大，注意模型上下文窗口）
- **配置快照**：把当前 Key/服务商/模型存为快照（如「DeepSeek 日常」「本地零成本」），之后在 **工具 → Papilot AI 配置快照** 一键切换，也可在工作台头部下拉直接切

### 流式输出说明

工作台与划词浮窗默认**流式**（逐字显示）。若你的网关不支持 SSE，插件会自动降级为一次性输出，功能不受影响；也可在设置「阅读器划词浮窗」里关闭流式开关。

## 三、期刊分区秘钥（easyScholar）

期刊分区列（中科院分区 / JCR 分区 / 影响因子）的数据来自 **easyScholar**。**0.56.0 起插件不再内置任何 SecretKey**（第三方 Key 不具备可转让的商用授权），需要你用自己的账号密钥：

> 未填写密钥时，分区列只显示插件内置的离线数据（覆盖常见期刊，不联网）；填好后在线数据自动接管。

### 填写密钥（必填，才能用在线数据）

1. 打开 https://www.easyscholar.cn 并注册/登录
2. 进入个人中心 → **API / 开放接口**（或「我的密钥」）页面
3. 复制你的 `secretKey`（32 位十六进制字符串）
4. Zotero → **编辑 → 设置 → Papilot** → 「条目数据列」分组 → 粘贴到 **SecretKey** 输入框

> 保存即生效，额度归你自己的账号。查询结果有缓存，重复刷新不消耗额度；额度用尽可点旁边的「清空查询缓存」。

### 换电脑不用重填：托管到自己的账号（0.64.0）

填好密钥后，点旁边的 **「存到我的账号」**——插件会把密钥加密后存到你自己的 Papilot 账号下：

- 加密方式是 **AES-256-GCM**，服务端落盘只有密文；主密钥不进任何备份，备份包被整体拿走也解不开。
- 换电脑 / 重装插件后，登录同一账号即可自动取回；本机不填也能查分区（设置页会显示「正在使用账号托管的 Key」）。
- 「从账号取回」手动拉一次；「删除托管」清掉账号里的副本（本机已填的 Key 不受影响）。

> 这不是「官方 Key」：服务端只当保管箱，不提供任何第三方额度，也不替你支付 easyScholar 的费用。

> **0.66.0 起凭据有了统一的「个人中心」**（0.67.0 扩到 8 类）：Zotero → **工具 → Papilot ▸ 功能中心 ▸ 账号与密钥**
> （或在「设置 → Papilot → 账号与会员」卡底部点「打开凭据中心」）。知网账号与密码、坚果云应用密码、
> 分区 SecretKey、自定义 AI 通道的 API Key、第三方文献源账号、Semantic Scholar 与 MCP 令牌都在一个窗口里
> 管理：默认脱敏显示，点「解锁查看」才出现明文并按设置自动隐藏；可设访问口令；已填的值可「存到账号」
> 加密备份，换机器一键取回（知网连用户名一起回来）。
>
> 0.67.0 新增**「仅托管」**（逐项可选）：值只存账号密文，本机不再留明文，运行时才水合并只放内存。
> 代价是离线或未登录 Papilot 账号时该项不可用，所以默认关闭、开启时会明确提示。
> 该窗口为专业版功能（免费账号打开是锁定卡，不显示任何值）。详见 `docs/账号与密钥中心-0.67.0.md`。

### 离线兜底

另有内置示例分区数据，且支持**自定义分区 JSON**——「自定义分区数据 JSON 路径」填一个本地 json 文件路径即可，格式：

```json
{
  "Nature": { "rank": "Q1", "if": 50.5 },
  "计算机学报": { "rank": "Q1", "if": 3.5 }
}
```

离线数据优先级高于在线查询，适合内网/离线环境。

## 四、阅读助手类功能

入口：条目上**右键 → Papilot**，或 **工具 → Papilot 功能中心**（推荐，34 项功能 6 类分组，支持搜索）。

### 1. 工作台（独立窗口）

**工具 → Papilot 工作台（独立窗口）**。核心界面：

- **顶部**：当前文献卡片（跟随主窗口选中切换）、AI 配置快照下拉、主题切换 🌙
- **三种模式**：
  - 📄 **本文对话**——把当前文献的题录+摘要（无摘要则全文）作为上下文，随时提问
  - 🔬 **深度研读**——注入**完整 PDF 全文**，要求 AI 引用原文细节回答，适合精读
  - 🌐 **全库对话**——不绑定文献，当通用学术助手用
- **工具条**：总结 / 翻译标题摘要 / 深度解读 / 全文对照翻译 / 思维导图 / **Prompt 技能库**
- **消息操作**：鼠标悬停 AI 气泡 → 复制 / 重答 / 存为笔记
- **会话**：左下角「会话 ▾」新建/切换/删除，最多保留 20 个，重启不丢；`Ctrl+N` 新建
- **快捷键**：`Ctrl+Enter` 发送，`Esc` 停止生成，生成中点「■ 停止」可中断且保留已生成内容

### 2. AI 问答侧栏

选中条目后，右侧信息栏出现「**AI 问答**」section，直接输入问题，基于该文献全文回答；回答支持富文本（加粗/列表/表格），可存为笔记、在多轮间追问。

### 3. 划词浮窗（阅读器里）

打开 PDF 阅读，**选中任意文字**即弹浮窗：

- **翻译**：译成目标语言（设置里可选 中文/English/日本語），专业术语保留英文括号标注
- **解读**：100-200 字解释这段讲了什么、在论文中的作用
- **追问…**：就这段文字继续多轮提问（自动带论文背景）
- 结果下方操作条：**复制 / 重试 / 写入批注**（在高亮上划词时，可把译文直接写进该高亮的批注）/ **在侧栏继续**（把这段送进 AI 问答侧栏）
- 设置里可开「**划词即自动翻译**」（带去重与限流，不会刷爆 API）

> **0.15.0 浮窗交互升级**：窗口加宽至 560px；右上角 **A− / A+** 五档缩放结果字号（自动记住）；**展开/收起** 一键把结果区撑到近全屏高；生成中随时可点 **停止** 取消输出。

### 4. PDF 速览侧栏

右侧信息栏「**PDF 速览**」section：不打开 PDF 就能看到摘要 + 全文开篇，快速判断这篇要不要读。

### 5. 三类一键笔记

右键 → Papilot：

- **AI 总结（生成笔记）**：300-500 字总结
- **AI 翻译标题与摘要**：学术语气翻译
- **AI 深度解读**：五段式（问题/方法/实验/创新/局限）结构化笔记

### 6. 全文对照翻译

右键 → Papilot → **全文对照翻译（左右双栏窗口）**（一次一篇）：打开左右双栏对照窗口——**左栏原文、右栏译文**，两栏等宽并随窗口宽度自适应；段落成对（同一行左右对应），滚动时逐段行级同步；窗口窄于约 720px 时自动切为单栏（原文/译文上下交替），也可在工具栏手动选择「自动 / 强制双栏 / 强制单栏」。工具栏可调字号（A− / A+）、复制全部译文，并一键「导出双语笔记」（上下结构的笔记，正文与旧版一致）。
分段字符数、双栏窗口字号可在「设置 → Papilot → 增强功能」调整。

右键菜单里仍保留 **全文对照翻译（AI 双语笔记）**：不打开窗口，直接逐段「原文引用块 + 译文」生成双语对照笔记。

### 7. AI 思维导图

右键 → **AI 思维导图**：生成层级大纲笔记（中心主题→主干→细节），可选导出 `.md` 文件，用 markmap/Obsidian 打开即渲染成导图。

## 五、笔记与卡片

- **收集批注为笔记**：把一篇 PDF 里所有高亮/批注按页序聚合成笔记
- **AI 解读批注**：AI 分析你划的重点反映了什么主线、你的关注点、下一步建议
- **按模板新建笔记**：内置「文献阅读笔记 / 精读卡片 / 速读记录」三套模板；设置里可自定义（每行 `名称=模板正文`，`\n` 表换行）。占位符：
  `{{title}} {{creators}} {{year}} {{pub}} {{doi}} {{abstract}} {{annotations}}（自动填批注）{{aiSummary}}（AI 总结）`
- **AI 制卡导出 Anki**：AI 基于全文生成问答卡 → 导出 `.txt`（制表符分隔）→ Anki「导入文件」选它，分隔符选 Tab 即可

## 六、批量分析

选中 **≥2 篇**文献后右键（上限默认 8 篇，设置可调）：

- **AI 文献矩阵**：逐篇抽取「研究问题/方法/数据/结论/局限」生成对比表 + 比较分析笔记
- **AI 文献综述**：生成 600-900 字带 `[1][2]` 引用编号的综述段落 + 文献清单
- **引文追溯**：分析参考文献与施引文献，生成引文网络笔记
- **参考文献一键入库**：把当前文献的参考文献批量搜索入库（挑感兴趣的勾选）

分类上**右键**：

- **分类条目统计**：条目数/附件/标签分布
- **文献统计图谱**：生成 HTML 报告（年份/期刊/作者/标签分布图），自动打开浏览器

## 七、库健康（元数据与附件维护）

- **中文文件名识别元数据**：从知网/万方式 PDF 文件名（`标题_作者_期刊_年份`）回填题录——**只处理标题还停留在文件名状态的条目**，已有元数据的一律不动
- **元数据补全**：按 DOI 查 Semantic Scholar，回写空缺字段（不覆盖已有值）
- **元数据规范清洗**：DOI 去前缀转小写、日期统一 `YYYY-MM-DD`、标题去尾句点、URL 去跟踪参数
- **智能清理**：全库扫描重复条目、无附件、缺元数据的条目并给处理建议
- **真假文献识别 / 粘贴文献列表核验**：AI 幻觉检测——检查某条题录是否真实存在，或粘贴一段参考文献列表逐条核验（写综述引用别人的 LLM 输出前建议过一遍）
- **开放获取 / Sci-Hub 补全文**：有 DOI 没全文的条目，先查 Unpaywall 合法开放获取版本；未命中时按设置接力 **Sci-Hub（按镜像顺序探测）→ Sci-Net（2021 年后新文献兜底）** 补 PDF。Sci-Hub 要求人机验证时会在 Zotero 中打开验证页——按提示完成验证（点「Нет」）后重跑即可，验证状态存在 Zotero 会话里；镜像不可达会在本次运行中暂停该渠道并提示。补充渠道默认开启，可在 设置 → 增强功能 中关闭或更换镜像（如 `sci-hub.box`）；仅供个人学术研究用途
- **附件按规则重命名**：按 `{author} - {year} - {title}` 模板（设置可改）批量规范 PDF 文件名

## 八、标签与阅读状态

- **AI 自动打标签**：AI 按内容建议标签，数量可设
- **规则打标**：自建条件规则批量打标（每行 `标签 | 字段 | 操作 | 值`），支持新条目入库自动应用
- **阅读状态**：右键标记「未读 / 在读 / 已读」（三态互斥）。自动化：新条目入库自动「未读」，打开 PDF 自动转「在读」；配合标签筛选或智能分类追踪阅读进度

- **期刊分区列**：见[第三节](#三期刊分区秘钥导入easyscholar)

## 十、常见问题

**Q：装完右键菜单里没有 Papilot？**
重启一次 Zotero；确认插件页里 Papilot 处于启用状态。

**Q：AI 功能报「请先填写 API Key」？**
设置 → Papilot → API Key 没填或没保存。填完点「测试连接」确认。

**Q：翻译/问答报 401 / 403？**
Key 错误或额度用完；工作台头部切换到可用的配置快照试试。

**Q：流式没反应，要等很久才一次性出全文？**
你的接口不透传 SSE，插件已自动降级；不影响结果，只是没有逐字效果。

**Q：分区列不显示数据？**
① 表头右键勾选了「期刊分区」列吗；② easyScholar Key 有效吗；③ 该期刊可能不在 easyScholar 库中（会显示 -）。

**Q：全文对照翻译只有部分段落？**
设置里「全文最大字符数」限制了对超长文献的截断，调大即可（注意模型上下文窗口）。

**Q：升级 Zotero 大版本后插件失效？**
Papilot 兼容 7-10；若刚发布的 Zotero 新版暂不兼容，等插件更新（自动更新通道会推送）。

**Q：数据安全吗？**
插件零遥测；AI 请求只发你配置的服务商；分区/被引量只调 easyScholar / Semantic Scholar / Unpaywall 公开接口。
