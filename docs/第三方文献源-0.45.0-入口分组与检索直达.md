### 可达性实测（2026-10-17 10:22，本机直连）

- 200：知网镜像节点 ×2、万方、维普、PubScholar、国家哲社、Sci-Hub 三站、CORE、arXiv、bioRxiv、medRxiv、NBER 系、Google 镜像 ×3、巨人学术 ×2、Semantic Scholar、思谋导航。
- **403（自动化探测被拦，浏览器可正常打开）**：百度学术、Europe PMC、DOAJ、ResearchGate → 均为 `probe: false`，面板不显示它们为「不可达」。
- **超时/不可达（本机网络）**：Google 学术官网、PubMed Central、SSRN → Google 官网与 SSRN 标 `probe: false`；PubMed 保留（有镜像需求的用户可直接打开）。

> `probe: false` 是本节最重要的工程决策：**探测失败 ≠ 站点不可用**，不能让面板用红点误导用户。

## 2. 检索直达（新增能力）

面板输入 DOI 或标题 → 点入口即落到该站的检索结果页，不再从首页开始点。

| 入口 | 模板 |
|---|---|
| 知网镜像 · 一/二 | `…/kns8s/defaultresult/index?kw={q}` |
| 万方 | `https://s.wanfangdata.com.cn/paper?q={q}` |
| Sci-Hub · 一/二 | `https://www.sci-hub.ren/{q}`（**仅 DOI**） |
| PubMed | `https://pubmed.ncbi.nlm.nih.gov/?term={q}` |
| Europe PMC | `https://europepmc.org/search?query={q}` |
| CORE | `https://core.ac.uk/search?q={q}` |
| arXiv | `https://arxiv.org/search/?query={q}&searchtype=all` |
| bioRxiv / medRxiv | `https://www.biorxiv.org/search/{q}` |
| Google 学术 | `https://scholar.google.com/scholar?q={q}` |
| 百度学术 | `https://xueshu.baidu.com/s?wd={q}` |
| Semantic Scholar | `https://www.semanticscholar.org/search?q={q}` |

- 纯函数：`isDoi(q)` / `canSearch(id, q)` / `urlFor(id, q)`——**DOI 专用源拿到非 DOI 时回首页**（`needDoi` 标记，面板提示「需 DOI 才能直取全文」），避免落到空结果页。
- 检索词只用于拼 URL，**不发任何请求**（`Zotero.launchURL`），网络行为白名单不变。

## 3. 面板改造（去噪 + 芯片化）

| 项 | 改前 | 改后 |
|---|---|---|
| 卡片描述 | 「文献虫 / 毕业助手」双站探测结果合并去重… | 中文库 / 英文全文 / 预印本 / 学术搜索：公开入口一键直达，可带入 DOI 或标题检索 |
| 说明行 | 来源与授权情况不明 + 机构代理类入口说明 + 镜像可能轮换… | 一行：实验功能 + 仅供检索定位 + 自行评估并遵守站点条款 |
| 列表 | 每行「状态点 + 名称 + 备注 + 打开按钮」（4 元素 × N 行） | 分组标题 + 芯片（状态点 + 名称），点击即开；无备注、无按钮堆叠 |
| 字号/密度 | 行高 ~34px，6 行 | 芯片换行排布，27 项约 6~7 行 |
| 检测 | 串行，每点 ≥1.5s（27 点约 40s+） | 并发 5 + 单点 8s 超时（实测 ~5–10s），带 `done/total` 进度 |

样式：`prefs.css` 新增 `.pp-ts-list / .pp-ts-group / .pp-ts-chips / .pp-ts-chip / .pp-ts-dot`，全部走既有 CSS 变量（明暗主题自适应）。

## 4. 健壮性守卫

- **漏写 `group` 的入口兜底进「其它」组**（`grouped()` 的 `_other` 分支）——新增入口时不会因元数据缺项而从面板静默消失。
- `checkEndpoints` 结果按 `ENDPOINTS` 顺序归一（并发完成顺序不可依赖）。
- `probe: false` 的入口既不出现在检测结果、也不进「可用 N/M」的 M。
- 面板脚本 `init()` 保留「Zotero 先跑脚本后插 DOM → 延迟重试」三段式（同 `prefs-cnki.js`）。

## 6. 日常维护

1. **加一个入口**：往 `ENDPOINTS` 追加 `{id, name, group, url}`（有检索页就补 `q`；站点会拦自动化探测就加 `probe: false`），跑 `node test/third-source.test.js` 与 `python scripts/check-wiring.py`。
2. **镜像轮换**：改 `url` 即可；面板「检测入口」会刷新状态点。思谋学术导航（`scmor`）作为「镜像自动更新」的兜底入口常驻。
3. **不要**在 `name` / 面板文案里加来源、出处、授权状态等说明——0.45.0 的既定口径是「只留实验提示」，接线扫描 §37.17 会拦住回退。
