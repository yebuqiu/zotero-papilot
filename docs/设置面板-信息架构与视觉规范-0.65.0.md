## 二、交互逻辑

```
┌ 工具条（吸顶）──────────────────────────────────────────────┐
│ [⌕ 搜索设置项…            ]       18 项 · 7 类  [全部展开][全部收起] │
└────────────────────────────────────────────────────────────┘
[直达：账号与会员] [AI 能力] [阅读与翻译] [文献获取] [条目与标签] …
── 账号与会员 ──────────────────────────────  1 项 ──
┌ ▣ 账号与会员 ─────────────────────────────────  ▾ ┐
│   登录后使用官方 AI 模型…                            │
└────────────────────────────────────────────────────┘
```

1. **折叠**（不变）：点标题行切换；状态写 `prefsFoldOpen`；「全部展开 / 全部收起」批量操作。
2. **搜索**（新增）：按「卡片标题 + 说明 + `data-search-strings-raw` 关键词」做 **AND 多词**匹配，
   最多 6 个词；命中项即时展开（`.pp-searching` 由 CSS 强制显示卡片体），组内零命中的大类标签一起隐藏；
   计数变成 `3 / 18 项` 并高亮；`Esc` 或 `×` 清空。**搜索不写 `prefsFoldOpen`**，退出即恢复原折叠状态。
3. **大类直达**（沿用并重做视觉）：`prefs-hotkeys.js` 按 `.pp-cat-label` 生成 chip，点击滚动定位并展开该组首卡；
   chip 文本取 `.pp-cat-name`，不会带上「N 项」。
4. **深链**：其他入口传 `_prefsFocus` 仍可展开并定位到指定卡（如 `channels`）。
5. **吸顶**：工具条 `position: sticky`，滚动到任意分组都能直接搜索/收起；≤560px 退化为普通块，不占屏。
