# 技能包商店全面审查与优化报告（2026-10-21）

> 范围：内置精选目录全部 45 个技能包（`chrome/content/scripts/features/skill-packs.js` 的 `_BUILTIN`）。
> 方法：逐包通读 manifest 全字段（desc/longDesc/prompts/glossary/noteTemplates/agentPreset），
> 对照 CommandTags 的 `{input}`/trigger 真实语义、AgentTools 注册表（13 个工具）与四槽安装机制核验可达性。
> 结果：**45 包全部修订深化 + 新增 11 包 = 56 包**，门禁全绿（preflight 107 通过 / 1 跳过 / 0 失败）。

## 一、审查发现

### P0 · 功能性缺陷（用户可感知的真 bug，9 处）

| # | 位置 | 问题 | 影响 |
|---|---|---|---|
| 1 | `cs-reader` | longDesc 承诺「③实验核对」但包内无此提示词 | 承诺-交付不一致，用户找不到功能 |
| 2 | `soc-reader` | longDesc 承诺「③量表信效度」但包内无此提示词 | 同上 |
| 3 | `eng-reader` | longDesc 承诺「③技术报告提取」但包内无此提示词 | 同上 |
| 4 | `response-letter/rebuttal-draft` | 用「【在此粘贴审稿意见】」文字占位而非 `{input}` | **trigger 命中后用户输入被整体丢弃**（CommandTags 契约：prompt 无 {input} 则整体替换），粘贴的意见永远送不到 AI |
| 5 | `meeting-minutes/minutes-organize` | 同上（【在此粘贴记录碎片】） | 同上 |
| 6 | `reading-priority-tags/priority-tag-suggest` | 同上（【在此填写你的研究方向】） | 用户输入「打优先级 NLP 方向」后方向文本丢失 |
| 7 | `math-reader` | 两枚提示词共用同一 trigger `^拆定理` | 「直觉重建」永不可达（触发恒被前者截获） |
| 8 | `medical-reader` | desc 写「PICO **五**要素」 | 事实错误——PICO 是四要素（P/I/C/O），prompt 本身也是四行 |
| 9 | `bio-reader/pathway-fig-read` | prompt 内「**我**不能看图」主语颠倒 | 发送后语义变成"用户看不到图"，AI 视角混乱 |

### P1 · 内容单薄（深度不足）

- **13 个包只有单枚提示词**（无第二提示词/术语/模板/预设配套）：期刊匹配、可复现性、学术改写、标签治理、方法/领域/优先级/工作流四标签包、投稿前自查、读书会、 econ/人文/心理三翻译包（有术语但单 prompt）。
- **直达触发覆盖率低**：58 枚提示词仅 30 枚有 trigger（52%），审稿、深读、术语自查、周报、改写等高频场景只能点标签。
- **12 个包缺 changelog** 字段，详情页更新历史空白。

### P2 · 结构性短板

- **7 个 Agent 工具零启用**：`search_arxiv`、`get_citation_count`、`search_notes`、`move_to_collection`、`export_bibliography`、`memory_read`、`memory_write` 注册表里有、没有任何技能包用——工具能力对用户不可见。
- **longDesc 全部是单段散文**（100-230 字）：没有「什么时候用 / 怎么唤起 / 得到什么」的分层，用户装完仍不知道触发条件。
- **模板槽位利用率 8/45**：六个阅读类包全都没有配套笔记模板；组会/实验/领读等场景缺模板承载。

## 二、改进措施（已落地）

### 修复（P0 全闭环）
1. 补齐三个阅读包承诺的第三枚提示词：`experiment-check`（实验核对）、`scale-reliability`（量表信效度核对）、`tech-report-extract`（技术报告提取）。
2. 三处失效占位符改为 `{input}` + 留空兜底话术（"若留空请先索要，不要编造"）——两条触发路径（输入直达/点标签）都可达。
3. `math-reader` 直觉重建改独立 trigger `^直觉重建|^找直觉`。
4. 医学包 desc 改「PICO 四要素」并扩充术语表 10→14 条。
5. 生物包机制图提示词改为明确的 AI 视角（"你无法查看图像，仅依据正文与图注重建"）。

### 深化（45 包全量）
- **longDesc 统一升级为三段式**：功能概述 + `▸ 适用场景` + `▸ 触发方式` + `▸ 预期产出`——每包都有具体的场景清单、唤起路径与可检查的产物描述。
- **trigger 全覆盖**：93 枚提示词 **92→93 枚有 trigger**（100%），常用词直达。
- **13 个单薄包扩充**：期刊匹配 +期刊匹配对照、可复现性 +复现路线规划、改写 +引用句改写、标签治理 +体系初始化、方法标签 +批量流程、领域标签 +领域复核、投稿自查 +秒退风险、实验记录 +实验复盘、阅读笔记 +笔记起草、读书会 +领读大纲模板、econ +题注翻译 等。
- 全部包补齐 changelog 并做 minor 版本递增（1.0.0→1.1.0 等）。

### 扩容（11 个新包，🆕 标记）
- **七个闲置 Agent 工具全部启用**：arXiv 前沿追踪（search_arxiv）、被引雷达（get_citation_count）、主题阅读清单（move_to_collection+export_bibliography）、研究记忆库（memory_read/write+search_notes）。
- **场景空白补齐**：学术英语润色（中式英语修正）、图表精读三法、文献汇报 PPT 大纲、Meta 分析数据提取、研究设计审查、科研诚信自查、主题词标签包。
- 新包诚实起步：不带官方评分/下载量字段（UI 容错已验证），社区评分随使用积累。

### 防回归守卫（新增 5 组断言）
`test/skill-packs.test.js` 新增：包内 trigger 不重复 / prompt 不含失效占位符 / longDesc 必含三段式 / 11 个新包锚定 / 七个工具已被预设启用。
