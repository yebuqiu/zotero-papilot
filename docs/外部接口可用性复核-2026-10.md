# 外部接口可用性复核（2026-10-23，0.75.1）

> 起因：翻译引擎查出「接口已下线但代码还按旧协议调」这类问题后，反问一句——
> **其他模块有没有同款毛病？** 本文是对全仓 122 个外部域名的实测复核结果。
>
> 方法：先从 `chrome/content/scripts/**`、`server/`、`tools/` 抽出全部 URL，
> 再对**默认路径就会用到**的接口逐个发真实请求（curl，非桩）。
> 判断标准不是"HTTP 200"，而是：**能不能拿到我们代码期望的数据**。
> 200 但返回错误页、000 超时、403 人机验证、404 结构已变，对用户而言都是"功能坏了"。

## 二、修了什么（4 项，均为"默认路径就坏"）

### 1. 在线词包：首选 CDN 国内不可达

- **现象**：设置 → 翻译 → 术语表 → 「获取在线目录」，国内网络下必然失败。
- **根因**：基址链只有 `cdn.jsdelivr.net` 与 `raw.githubusercontent.com`，两者在本机实测
  分别 000 / 000。这不是"偶尔慢"，是**两条都不通**。
- **改动**：加 `fastly.jsdelivr.net`（jsDelivr 的另一个边缘域名，内容完全一致）并置于首位；
  时间戳破缓存的逻辑从"仅第一个 base"放宽到"任一 jsdelivr 边缘"。
- **验证**：fastly 实测 200，返回 open-termbank **v2.2.0 / 28 域**，结构与 `fetchCatalog` 期望一致。

### 2. Sci-Hub 补全文：默认镜像首位已死

- **现象**：点「补全文」长时间无响应（首次最明显）。
- **根因**：默认链首位 `sci-hub.ru` 及次位 `.se` / `.st` **全部 TCP 不可达**，
  而单镜像超时是 **30 秒** → 三个死镜像就是 90 秒。
- **改动**：① 按实测重排为 `ren → ee → ru → se → st → hkvisa → mksa`；
  ② 单镜像超时 30s → **12s**（正常镜像 1~9s 就返回）；③ 整条链加 **40s 总预算**；
  ④ 补一次「上一代 7 镜像默认链 → 新顺序」的迁移（同样只动从未自定义的用户）。
- **验证**：单测 116 项（新增旧链迁移断言）。

### 3. Semantic Scholar：429 直接失败，用户只看到空白

- **现象**：相关文献 / 引用上下文面板偶发空白，没有原因。
- **根因**：无 API Key 时走共享额度池，实测直接 **429**；旧实现把 429 当普通异常抛出，
  面板只显示"失败"或空列表，用户分不清是限流、没配对还是自己没登录。
- **改动**：`_req` 加一层「429/5xx 退避重试一次」（读 `Retry-After`，上限 5s）；
  仍 429 则抛**能落地**的文案：提示填写免费 S2 API Key 或稍后重试。超时不重试。
- **验证**：`citation-context` 143 / `related-papers` 112 断言全过（复用同一 `_req`）。

### 4. PubMed：单源 25s 串行超时

- **现象**：勾了 PubMed 的订阅，点「立即检索」要转很久。
- **根因**：五个源**串行**，PubMed 在国内整段不可达（实测 46s 无响应），
  而它的超时是默认的 25s —— 一源吃掉半分钟，后面的源还没开始。
- **改动**：超时收紧到 **12s**；加「连接层失败 → 5 分钟冷却」，
  冷却期内直接返回可读原因（不再每次白等）。**429/5xx 不冷却**（对方还活着，不该放弃）。
- **验证**：`sub-sources` 186 / `search-subs` 536 断言全过。

## 三、只报告、未改的

- **公网通道当时未运行**：`pp.xinglintools.top` 502，而客户端 `Account.SERVER_DEFAULT`
  写死这个地址 → 账号登录、会员、官方 AI 网关**全部不可用**。这是本轮影响面最大的故障，
  但属运维态（隧道进程没起）而非代码缺陷，**已启动并自检 200**。
  → 计划任务 `PapilotGuard` 早已不注册，开机不会自启；要长期稳定需重新注册或加进开机启动。
- **第三方文献站（文献虫等）**：`060193.top` / `b88r.top` / 各卡密站属灰色渠道，
  默认关闭，且历史上已结论「不建议」；不做维护性修复。
- **`rss.sciencedirect.com` 404**：Science 的 ISSN 映射到该 RSS 已停服；
  已有 `science.org/action/showFeed` 兜底（实测 200 61KB），不影响。
- **CNKI**：入口正常，详情页需登录态与反爬处理（分册 24）；不在本轮范围。

## 四、给以后的自检清单

新增/改动外部接口时，先问四个问题（本轮每个问题都命中了至少一处）：

1. **它今天还活着吗？** —— 用真实请求验，别只看单测绿。
2. **活着就代表能用吗？** —— 200 可能是错误页、403 可能是人机验证、404 可能是路径变了。
3. **默认路径通吗？** —— 死镜像排首位、首选 CDN 被墙，用户第一次用就失败。
4. **失败说得清吗？** —— "空白"和"限流，请这样做"是两种产品。
