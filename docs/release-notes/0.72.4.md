## 翻译设置拆成三张卡

真机反馈：「翻译引擎与术语表」一张卡塞了引擎选择、回退链、稳定性参数、自建服务、术语表、
PDF 对照翻译六块内容，又长又乱。本版按功能边界拆开：

| 新卡 | 内容 |
|---|---|
| **翻译引擎** | 引擎选择、回退与稳定性（新增小节标题）、自建/离线、数据去向、引擎列表 |
| **术语表与全文翻译优化** | 术语表编辑框、导入导出、在线词包、全文对照的三个优化开关 |
| **PDF 对照翻译（左原版 / 右译文）** | 右栏形态、译文字号、同步滚动 / 缩放 |

所有设置项的 id 与存储键不变，已保存的值不受影响；三张卡各自记忆折叠状态。
「阅读与翻译」分类由 3 项变为 5 项，顶部计数同步为「21 项 · 7 类」。

## 邮箱可点性

账号卡里的邮箱从灰色文字改为链接色——它一直可以点击切换明文显示，但灰色让人以为只是展示文本。
