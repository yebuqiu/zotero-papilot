一个问题修复：**订阅了期刊，左侧却看不到任何东西**。

## 为什么会这样

左侧【订阅】是 Zotero 原生的 RSS 订阅区，而 Papilot 的检索订阅走的是 OpenAlex / Crossref
接口检索 + 自动入库，两套机制本来不相通 —— 期刊订好了、文章也进来了，但左侧没有任何入口。

## 修法：一条订阅落到两个看得见的地方

订阅期刊后（或点「同步到左侧面板」）：

- **库内分类**（100% 覆盖）：在「我的文库」下自动建「订阅期刊 / <刊名>」分类。
  之后该刊的新文章入库时自动归类；已经入库的历史文章一并回填（按入库时打的
  `#订阅/<订阅名>` 标签找回）。中文刊（中草药、国际心脑血管病杂志等）照样有效，离线可用。
- **原生 RSS**（尽力而为）：对能找到真实 RSS 的刊，再在左侧【订阅】里挂一条源，
  点开就是这本刊的最新文章。已覆盖：
  - Elsevier / ScienceDirect（按 ISSN 直连，Lancet、Cell 等一大批）
  - Nature 系（nature.com 的刊路径）
  - Science（AAAS）、BMJ、PNAS、NEJM（各自固定 RSS）
  - 中国知网（按刊号；内置中草药、中华心血管病杂志、中国中药杂志等）
  找不到 RSS 的刊不会硬挂空源 —— 分类照常可用。

## 界面上的变化

设置 → Papilot → 检索订阅 → 「我的订阅」下方新增：

- **同步到左侧面板**按钮：建分类 + 回填历史文章 + 尝试挂 RSS，一次做完
- **状态行**：`期刊订阅 N 本 · 左侧「订阅期刊」分类 N/N · 左侧【订阅】RSS N/N`，
  一眼看出哪本刊还没落地

## 不会做的事

- 不删你的数据：取消订阅只停止后续归类，已建分类与文章原样保留
- 不重复建：分类按名字复用，RSS 源按 URL 去重
- 不阻塞入库：归类/RSS 失败只记调试日志，条目照常保存
