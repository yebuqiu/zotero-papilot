# Papilot 0.72.3

这版只做一件事：**把 0.72.2 没做完的可访问性收尾做干净**。

## 用户能感知到的变化

1. **深色主题不再是「半深半浅」**
   以前只有在系统是深色时面板才整体变深。用户自己在 Papilot 里手动选深色、而系统仍是浅色时，
   一部分令牌翻了深色、另一部分没翻，会出现浅底配浅字、深底配深字的混搭。
   本版给设置面板补了显式深色分支，并声明 `color-scheme`，让原生复选框、下拉弹层、
   滚动条跟着一起翻——深色下未勾选的复选框以前是个**纯白方块**，看着像已勾选。

2. **边界看得清了**
   输入框、选择框、文本域、按钮与可点选项的描边原本只有 1.36:1（浅）/1.68:1（深），
   在低对比度屏幕上几乎看不出输入区在哪。现在统一到 3:1 以上。

3. **键盘能用了**
   运行时动态生成的一批可点元素（会员选项、数据集 chip、行内 chip 删除钮、付款弹窗关闭钮）
   以前是 `span` + click，鼠标能点、键盘到不了。现在都是真按钮，Tab 能到、Enter 能触发、
   焦点环清晰可见。

4. **术语表能正常编辑**
   编辑框被输入框样式压成单行（28px），几百条术语只能横向滚动。已恢复多行。

## 没有做的事（明确边界）

- **卡片轮廓、1px 分区线保持浅描边**。它们不是控件边界，WCAG 1.4.11 不适用；
  强行加深只会让整面板变成硬边网格。门禁报告里照实测值列出，标注为「装饰性豁免」。
- **另外 6 个独立窗口（凭据中心、技能商店、向导、工作台、审阅台、聊天窗）未纳入本轮**。
  它们与本面板共用令牌，同样的原生控件问题存在；但本轮没有对它们做明暗实渲验证，
  不做未经验证的连带改动。

## 工程侧

- 设计门禁从一次性脚本沉淀为可复跑资产：`scripts/audit/` 下四项（对比度 / 静态 / 实渲 / 运行时）。
- 「设置面板运行时审计」已接入 `preflight.py`：JS 拼串里的 emoji 与 span 假按钮今后会被
  发版门禁拦住——0.72.2 正是因为门禁只看 markup，漏掉了运行时生成的 7 个 emoji 与 10 个 span 点击目标。
