三类改动合并发布：**标签管理**（新）、**按期刊订阅**（新）、**Papilot Cite 命令修正**。

## 新增：标签管理

左下角标签列表里**右键任一标签** → 「Papilot 标签工具」，或从「工具 → Papilot → 标签管理器」打开独立窗口。

- **批量操作**：重命名、合并、加父标签、改路径前缀、套用配色，一次处理一批标签
- **一律先预览**：执行前列出「会改哪些标签、影响多少条目」，确认后才动手
- **自动快照**：删除/改名/改色之前先存现场，「快照与撤销」里可回滚（只回滚标签关系）
- **保护名单**：默认保护 `#状态/*`、`#治理/*`，批量删除默认跳过，需要显式勾选
- **标签体检**：重复标签、缺父级、只用过一次、写法变体（大小写/全半角）一目了然
- **体系与导入导出**：保护名单编辑、标签表导出 CSV

## 新增：按期刊订阅

设置 → Papilot → 检索订阅 → 顶部「按期刊订阅」。

- 内置 **525 种期刊 / 18 个学科**，带中文别名，ISSN 已逐条在线核验
- 输入框敲 `柳叶刀`、`NEJM`、`0028-4793` 或 `临床医学` 都能命中，点「订阅」即可
- 目录外的期刊自动去 OpenAlex 的 3 万+ 刊源里找，结果标「在线检索」
- 默认每天 08:00 取近 30 天新文章、每次最多 10 条自动入库
- 期刊条件可与关键词/作者叠加（例如「The Lancet + 心肌梗死」）
- 不用再去期刊官网找 RSS 地址，也不用自己查 ISSN

## 修复：Papilot Cite（WPS 加载项）

- 「刷新」「插入引文」「文献表」之前会**点了没反应**：用错了命令名（`refreshDocument` 在 Zotero 里不存在）
- 现在改用官方命令：`refresh` / `addEditCitation` / `addEditBibliography`
- 插入引文时若光标已在某条引注内，会改为编辑那条，不再把新引文嵌进旧引文
- 插入文献表时若已有文献表，会更新而不是再新建一个
- 命令名先过白名单校验，写错会在发请求前直接报错（不再静默等 30 分钟）
