阅读与翻译3 项
翻译引擎与术语表 划词、全文对照、标题摘要共用一套引擎；可选 AI 大模型、免费引擎或自填密钥，术语表保证全文一致 ▾
源语言一般选「自动检测」；目标语言对全部翻译功能统一生效（与「阅读器划词浮窗」卡片里的选择是同一项）。
稳定性三件套：单路预算到点就换下一个引擎；总预算到点就停整条链；某引擎刚失败过会在冷却期内被自动跳过（由其它引擎顶上），避免一次网络抖动把整条链跑满。
自建 / 离线（可选，零成本且无额度限制）
  • 本机跑一个翻译服务即可摆脱额度与外网依赖：LibreTranslate（默认 5000 端口）、Lingva（3000）、DLX（1188）
  • 点下面的按钮会自动发现并一键填入地址，无需新增任何引擎
数据去向：免密钥引擎会把待译文本发往对应服务商（Google / 微软 / 腾讯 / 有道等）；「AI 大模型」引擎发往你在「AI 模型通道」里配置的通道；自建引擎（LibreTranslate / Lingva / DLX）与本地 Ollama 不出本机。未发表的稿件建议优先走自建或本地通道。
术语表与全文翻译优化
  • 语法：每行一条「原文 = 译文」（也可用 => 或 TAB 分隔；# 与 // 开头为注释）
  • 可选第三段标注领域——「原文 = 译文 | 领域」（多标签用 ; 分隔，如「myocardial infarction = 心肌梗死 | 医学」）
  • 仅对「AI 大模型」引擎生效：翻译时注入提示词，待译段落命中的术语优先注入，保证专业术语全文一致；Google / DeepL 等专用引擎没有指令通道、无法使用术语约束
  • 可导入开源术语库的 CSV / TSV / JSON 文件（如 IATE 导出、计算机 / 医学领域词表）；翻译完成后状态行会汇报「术语一致 n/m」
