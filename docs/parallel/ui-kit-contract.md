# ui-kit 组件契约（B2.0 · 2026-10-20）

> 本文件是**并行开工的前置契约**：B2 的四个窗口迁移、B3 的向导窗口都按这里的类名与尺寸写，
> 谁都不许临时发明新类。实现文件：`chrome/content/ui-kit.css`（B2.0 产出）+ `test/ui-kit.test.js`（类名快照）。

## 1. 边界：kit 只管「叶子控件」，不管布局

| 归 ui-kit | 归各窗口自己 |
|---|---|
| 按钮 / 输入 / 下拉 / 文本域 / 芯片 / 卡片外壳 / 行内标签 / 提示与状态文字 / 空态 | 窗口骨架（头部、分栏、气泡、消息列表、编辑器容器）与窗口私有类（`pp-wb-*` / `pp-cw-*` / `pp-ss-*` / `pp-rw-*`） |

理由：窗口骨架差异大（聊天 vs 列表 vs 表单），强行统一只会把布局写死；控件才是重复度最高、
用户感知最强的一层（高矮胖瘦、圆角、聚焦环、禁用态）。

## 2. 类名清单（**只增不改**）

| 组 | 类名 | 说明 |
|---|---|---|
| 按钮 | `.pp-btn` | 常规按钮，高 28 |
| | `.pp-btn-primary` | 主操作（每屏最多 1 个） |
| | `.pp-btn-sm` | 小号，高 24，用于行内次要操作 |
| | `.pp-btn-lg` | 大号主操作（聊天/编辑器发送按钮），高 36 |
| | `.pp-btn-ghost` | 无边框，悬停才显底 |
| | `[disabled]` | 统一 0.5 透明度 + `cursor:default` |
| 输入 | `.pp-input` | 单行输入 / 数字 / 密码，高 28 |
| | `.pp-select` | 下拉，高 28 |
| | `.pp-textarea` | 多行，行高 1.65，可纵向拉伸 |
| 芯片 | `.pp-chip` / `.pp-chip-on` | 药丸标签，选中态走 `-on` |
| 卡片 | `.pp-card` / `.pp-card-head` / `.pp-card-body` | 12 圆角 + 1 档阴影；head 可点击时由窗口自行加 `role=button` |
| 排版 | `.pp-row` / `.pp-label` / `.pp-hint` / `.pp-msg` | 行容器 8px 间距；label 12.5；hint 11.5 次要色；msg 12 + 最小高 16 |
| 状态文字 | `.pp-msg-ok` / `.pp-msg-warn` / `.pp-msg-err` | 接在 `.pp-msg` 上表示成功 / 警告 / 错误，颜色取语义令牌 |
| 空态 | `.pp-empty` | 居中灰字 + 12px 上下留白，用于「暂无数据 / 未配置」 |

## 3. 尺寸与令牌（唯一取值）

| 项 | 值 | 令牌 |
|---|---|---|
| 控件高度 | 28（常规） / 24（`-sm`） | — |
| 圆角 | 控件 6 / 小卡 8 / 卡片与弹层 12 | `--pp-radius-sm/md/lg` |
| 间距 | 4 / 8 / 12 / 16 / 22 | `--pp-sp-1…5` |
| 字号 | 10.5 / 11.5 / 12.5 / 13.5 / 15 | `--pp-fs-xs…xl` |
| 聚焦环 | `box-shadow: 0 0 0 3px var(--pp-focus-ring)` | — |
| 颜色 | 只用 `--pp-*` 语义令牌（`ui-tokens.css`），**不写死色值** | — |

> 控件高度只有两档。任何窗口需要第三种高度时，先改契约（评审后才改），不许就地写 inline。

## 4. 硬规则

1. **不加 `!important`**；不覆盖窗口私有类的既有语义。
2. 新类一律 `pp-` 前缀，且在 `test/ui-kit.test.js` 的类名快照里登记。
3. 只允许**删掉**窗口内被 kit 取代的 inline 样式，不允许顺手改窗口布局。
4. 迁移一个窗口 = 一个 commit；回滚只回滚该 commit，不牵连其他窗口。
5. 迁移后必须人工目视一次（明/暗各一张），并在 commit message 里写「已目视：<窗口> 明/暗」。

## 5. B3 消费面

向导窗口只需这 8 个类：`.pp-btn` `.pp-btn-primary` `.pp-btn-ghost` `.pp-input` `.pp-select`
`.pp-label` `.pp-hint` `.pp-empty`。因此 **B3.1 只依赖 B2.0（契约）**，不等窗口迁移完成。
