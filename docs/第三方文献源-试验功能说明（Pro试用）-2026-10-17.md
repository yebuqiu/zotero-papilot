# Papilot 实验功能说明：第三方文献源（Pro 试用）

- **状态**：实现完成、门禁全绿；**未提交 git、未发版**（建议版本落点 0.44.0，实验特性）
- **依据**：双账号探测报告《文献虫站点文献入口探测-2026-10-16.md》+ 合并数据 `merged/combined_entries.csv`（438 条去重记录）
- **一句话**：为「文献虫 / 毕业助手」等文献代查站提供 **自带卡号的登录自检 + 一键直达入口**，面向 Pro 会员试用，默认关闭。

---

## 1. 功能定位与边界（重要）

**做什么**：
1. 在插件内保存第三者站点的卡号/密码（**只存本机**）；
2. 「保存并测试登录」——向站点发 **1 次**登录请求，验证卡号有效性，并识别站点特有的失败态（尤其是**单会话被占**："同一帐号同一时刻只能一人在线"）；
3. 「打开文献下载入口 / 打开用户中心」——用系统浏览器直达站点页面，由用户自行完成检索与下载。

**明确不做**（工程 + 合规双重边界）：
- ❌ 不代下载、不解析文献内容、不批量请求（站点本身也没有"按 DOI/篇名取全文"的条目级 API，本质是**入口导航站**）；
- ❌ 不共享账号：站点限制同一账号单会话，多端共用必然互踢（实测复现）；
- ❌ 不提供任何绕过验证（点击验证码 / 单会话限制）的能力；
- ⚠️ 站点为第三方灰色来源（机构账号池、非授权渠道），**默认关闭**；启停与使用由用户自行评估风险并遵守目标站点条款。

## 3. 访问权限控制（服务端不介入，全部在客户端）

### 3.1 Pro 软门控（`ThirdSource.proGate()`）

| 情形 | 结果 | 说明 |
|---|---|---|
| 已登录 且 `Account.isPro()` 为真 | ✅ 放行 | 有效期内 Pro（含到期判断） |
| 已登录 且 **明确非 Pro**（Free / 已过期） | ⛔ 拦截 | 提示「该实验功能面向 Pro 会员试用……可在设置面板升级」 |
| 未登录 | ⛔ 拦截 | 提示先登录 Papilot 账号 |
| 会员信息未知（旧服务端 / 无 membership） | ✅ 放行 | **既有纪律：判定不出时绝不锁用户** |
| 账号模块缺失 / 判定抛错 | ✅ 放行 | 同上（同 rank-column 的 easyScholar 口径） |

- 门控在**每个动作**上执行（面板按钮、菜单入口），不只靠 UI 隐藏。
- ⚠️ 性质说明：这是**产品分层**（软门控），不是安全边界——本地 pref/代码可绕过；与该功能不依赖服务端的事实一致。

### 3.2 总开关与凭据

- `thirdSourceEnabled` **默认 false**：关闭时菜单入口会「弹提示 + 打开设置面板」而不打开站点；卡片可随时开关（Pro 试用期间建议开启体验）。
- 凭据：`thirdSourceUsername / thirdSourcePassword`（密码 **base64 混淆，非加密**）；只存本机 profile、不上传、不进 git；「清除凭据」一键清空。**请勿使用与其他平台相同的密码**（站点为 HTTP 明文）。
- 网络行为白名单（可审计）：模块内 **仅 1 处** 网络调用 = 登录自检（`Zotero.HTTP.request`，POST ×1，请求间隔 ≥1.5s 节流）；其余动作均为 `Zotero.launchURL`。

## 4. Pro 会员适用范围（试用口径）

- **面向**：Pro 会员（含有效期内）试用；功能为**实验性**，可能随站点变化随时调整或下线。
- **不在范围**：Free / 过期用户（拦截并引导升级）；未登录用户。
- **例外放行**：客户端无法判定会员状态时放行（见 3.1，纪律使然）。
- **服务端**：不新增任何服务端依赖、不上报任何使用数据；Pro 判定复用既有账号体系（`/api/auth/me`、`/api/membership` 缓存）。

| 站点 | 去重记录 | 交接有效 | 状态要点 |
|---|---|---|---|
| 文献虫（b.r88r.top，账号 A） | 274 条（入口 248 + 文章 26） | 265 | 三库（中文/英文/医学）；8 个栏目无资源；sxxs 死域 38 入口 |

| **合并** | **438 条**（`merged/combined_entries.csv`） | — | 家族矩阵与域名并集见 `merged/stats.md` |

- **两站重叠**：英文库主体（Nature/IOP/RSC/ACS/Springer/Wiley/ACS/Taylor 等）几乎等价；中文库部分重叠（维普/超星/读秀/龙源）。
- **A 独有**（主要医学库）：UpToDate、EBSCO、PubMed、中华医学会、万方（多机构）、Reaxys、CSSCI 等。
- **B 独有/差异**：Scientific.Net、F1000、IEEE 的 247 列形式、"临时"（WoS 变体）等（详见 `merged/stats.md` 差异节）。
- **共同缺陷**（两站一致，接入时必须接受）：`www.sxxs.shop` 已死（A38/B19 个入口指向停车页）、`hggfdd.top` 404、`zjlib` 代理 403、`api.sjuku.top` 连接超时、CNKI 网关点击验证码、单会话限制。
- 因此 v1 定位为「**登录自检 + 入口直达**」而不是自动取全文；若未来做 v2（如"选中条目 → 打开外部检索页并用题名预填"），需另行评审并保持默认关闭。

## 6. 发布与灰度建议

1. **版本**：建议 0.44.0 独立发版（实验特性标注）；**不要混入 0.43.2 的防窥屏批次**（两批改动虽文件不冲突，但发布说明应分开）。
2. 发布前：按项目七步流程（preflight → 显式 add → tag → pushgitee → GitHub tag/Release → Gitee 发行版）。
3. 灰度观察点：启用率、登录自检成功率/失败码分布（busy/bad-credentials/unknown）、入口打开后用户实际到站率；站点失效（域名轮换）时的降级文案是否清晰。
4. 止损：站点大面积失效或投诉时，置 `thirdSourceEnabled` 默认说明并在更新说明中提示下线（客户端无需服务端支持）。
