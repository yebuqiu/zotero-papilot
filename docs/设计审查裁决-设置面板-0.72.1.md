# Papilot 设置面板设计审查裁决书（0.72.1）

> 审查人：design-critic（反AI味UI设计工作室）｜日期：2026-10-21
> 对象：`chrome/content/prefs.xhtml`（1809 行，19 卡 / 7 类）+ `chrome/content/prefs.css`（1321 行，令牌制）+ `docs/预览-设置面板-0.72.1.html`（实渲预览）
> 配套改进方案：`docs/设计改进方案-设置面板-0.72.1.md`

## 一、工具化门禁实测结果

### 1. 对比度（逐对真实计算，含 rgba 合成后背景）：43 对实测，10 对不达标

文本 AA（4.5:1）失败 6 对：
| 位置 | 组合 | 实测 |
|---|---|---|
| `.pp-btn-primary`（prefs.css:539）深色主按钮 | #ffffff on #4493f8 | **3.10:1**（hover 底 #2f81f7 上白字 3.75:1） |
| `.pp-pill-ok` / `.pp-dlg-badge-ok`（浅） | #1a7f37 on #e4f0e8（合成） | **4.34:1** |
| `.pp-pill-warn` / `.pp-mb-renew` / `.pp-ai-tier-trial` / `.pp-dlg-tail`（浅，均 12px 小字） | #9a6700 on #f3ede0（合成） | **4.17:1** |
| `.pp-count-hit` / `.pp-anchor-active` / `.pp-dev-row-cur`（深） | #4493f8 on #253244（合成） | **4.19:1** |
| `.pp-mb-renew-expired`（深） | #f85149 on #3f2b2f（合成） | **3.92:1** |

非文本 3:1 失败 4 对：输入框/卡片描边 浅 #d8dee4 on #fff = 1.36、深 #3d444d on #21252b = 1.56；焦点环合成 浅 ≈1.33、深 ≈1.55（`--pp-focus-ring` alpha 仅 .20/.28）。
其余 33 对（正文/次要/占位/链接/状态色 × surface/surface-2/field × 明暗）均 ≥4.5 通过。静态扫描 140 对仅作初筛（2 对误报已人工排除）。

### 2. 裸色值：未归零
工具报 70 处，其中 60 处为 .pp-root 令牌定义区（放行）；**组件区真实违例 10 处**：prefs.css:539/545/587/626/772/980/1267（裸 #ffffff）、1197（裸 rgba(0,0,0,.42) 弹窗遮罩）、599/601（var() 兜底裸值）；另有 xhtml:1794-1795 内联 `background:rgba(127,127,127,0.18)` 与 `var(--pp-accent,#4b7bec)`——#4b7bec 是调色板外野蓝色。

### 3. emoji 硬门禁：失败
预览 HTML 命中 45 处 + prefs.xhtml 正则复核 77 个 emoji 字符：**19/19 张卡片图标全是 emoji**（👤🔌🎛️🧩🌐💬📖📚🧪📡⏰📊🏷️🧰🧭⌨️☁️…），按钮内 ⚡🔍📡↻👁🎲🌄🔑，图例 ☀️🌙⚡🖼。零容忍项。

### 4. slop_tells 严格复核：63 命中，1 项成立
18 条「空洞三连」初筛均为具体功能枚举，不判俗气。成立项：`.pp-cat-label::before` 与 `.pp-theme-cat` 的 3px 单侧 accent 竖条（用在分区标题而非卡片/吐司，判 Minor）。紫渐变/玻璃拟态/等距三卡片未命中。

## 三、令牌纪律实测（0.65.0 宣称收敛，实际未遵守）

- **字号**：令牌 5 档（10.5/11.5/12.5/13.5/15）；实际出现 **12 种 px 字号，10 种不在令牌内**（9/9.5/10/11/12/13/14/16/17/24）。12px 用 16 次成事实正文级却不入令牌；9px/9.5px 低于令牌下限
- **间距**：令牌 5 档（4/8/12/16/22）；实际 margin/padding/gap 出现 **18 种值**，用量最大的 10px（40 次）不在刻度内；xhtml 内联样式另含 52 处裸值。**间距令牌制名存实亡**
- **圆角/阴影**：3+3 档被遵守（通过）

## 四、P0 发现（阻断/无障碍硬伤）

1. **emoji 硬门禁全灭**（位置见门禁 3）→ 换内联 SVG（currentColor）或纯文字
2. **深色主按钮对比度 3.10/3.75** → 深色下 accent 作按钮底需加深（#1f6feb 级别并复测）或改深色文字
3. **7 处 span 假按钮 + 弹窗 span 关闭钮键盘不可达、付款弹窗无 Esc** → 改 `<button>` 或补齐 role/tabindex/keydown；弹窗加 Esc 与焦点回收
4. **label 0/98 关联** → 批量补 for= 或改包裹式；搜索框补 aria-label

## 五、P1 发现（效率/一致性）

5. **术语表 textarea 被压成单行**（xhtml:709 `class="pp-input"` 命中 .pp-input height:28px，rows=5 失效，wrap=off 只能一行高横向滚动编辑几百条术语；已截图实证）→ 改 class="pp-textarea"
6. **「测试连通」五种说法五种反馈位**：通道行叫「实测」结果扔卡片底部 #pp-ch-test-result（prefs-account.js:1801）；翻译行叫「测试」且行内反馈（prefs-translate.js:632 修过同类问题）；另有「检测权限/检测入口/保存并测试」→ 统一动词与行内反馈位
7. **检索订阅新建表单 15+ 字段平铺**（xhtml:990-1049）、**云同步 8 组高级参数平铺**（1671-1762）→ 高级项收折叠区（渐进披露）
8. 状态色合成底 4 对不达 AA（门禁 1）→ 提文字色深度或降底色 alpha
9. 焦点环合成 1.33/1.55 → 提 alpha 至 ≥.5 或换实色 2px outline
10. OCR 子块用原生 XUL menulist/checkbox（xhtml:1400-1420）与全面板控件体系两张皮；pp-cloud-policy/direction 用 pp-input 充当 select → 统一
11. 「AI 参数与智能体」一卡 8 子分区（含 3.3e 四个无标题裸 checkbox，xhtml:528-547）；「账号与会员」一卡 7 子系统 → 拆卡或加子分区标题
12. 术语表子分区说明单段 250+ 字（xhtml:707）、自建引擎说明同样字墙（698）→ 拆条列点

## 八、四条核心任务流走查

① **配 AI 通道并测试**：入口可达（搜索/chip/向导）；断点在「实测」反馈跳到卡片底部（点完按钮视线内无变化——翻译卡已修的毛病这里还在）；厂商预设→填 Key→保存链路顺
② **翻译引擎+密钥+测试**：行内测试反馈好；断点是「带密钥标记的引擎需先填好凭据」未说清去哪填（行内展开还是 vault，说明埋在 770 行 desc 里）
③ **导入术语表 CSV**：导入→合并→msg 汇报链路成立；但编辑器 28px 无法自查导入结果，只能信 msg 计数
④ **新增检索订阅**：四条路径并列造成选择困难；手动表单 15+ 字段无分组；「试跑预览→保存订阅」顺序合理，是四条流里恢复路径最好的（有取消编辑）
