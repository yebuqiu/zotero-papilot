## 具体借鉴点

### ui-theme.js（界面主题）
- **yaobian-zotero**（MIT）：
  - CSS 变量映射契约——Zotero 7+ 界面颜色由 `--material-*`（面）/`--fill-*`（字）/`--color-accent`、`--arrowpanel-*` 等（强调/弹窗）驱动，覆盖这批变量即可整窗换肤；
  - `<style>` 注入在窗口 author 级、`!important` + 文档顺序取胜，作用域收在 `#main-window` 不污染 reader 子文档；
  - `Services.wm.getEnumerator` 枚举全部 chrome 窗口（`Zotero.getMainWindows()` 拿不到设置窗口）；设置窗口会被 Zotero 自行 reload，需 load 事件重挂；
  - 选中行（`.selected`）是自绘中性灰、不吃变量，必须单独覆盖；
  - "核心色板角色 + 派生角色（tab/ink2/ink3 由基色混合）"的主题数据组织。
- **zotero-night**（GPL-3.0）：Nord 色板基调（nord-night 主题配色取自 Nord 官方色板 #2E3440/#88C0D0 等，Nord 色板本身以 MIT 发布）；"UI 与阅读器一起换色"的产品形态。
- **Primer**（GitHub 设计系统，MIT）：primer-light/primer-dark 两套标准主题的色值基础。

### pdf-theme.js（PDF 阅读主题）
- **zotero-pdf-background**（无 LICENSE 文件——机制思路借鉴，代码原创重写）：
  - 核心机制洞察：Zotero 内置 pdf.js 的 `.textLayer` 覆盖在 canvas 之上且默认透明，**半透明叠色**（其默认 `opacity:0.3`）可实现"护眼底色"而完全不动 canvas 渲染；
  - `Zotero.Notifier` 监听 tab 事件 → `Zotero.Reader.getByTabID()` → `reader._iframeWindow` 定位 viewer.html iframe；
  - 阅读器工具栏中部（`.toolbar div.center`）注入切换按钮的交互；
  - `#secondary-view` 挂 MutationObserver 兼容分屏视图。
- **zotero-night**（GPL-3.0）：夜间模式 = `filter: invert(1) hue-rotate(180deg)` 反色 canvas（黑纸白字、色相保持），pdf.js 社区标准做法；viewer 底色同步加深。

### 界面壁纸（0.16.1，ui-theme.js 壁纸部分）
- **yaobian-zotero**（MIT，其壁纸选择器清单上游为 endoretic/zotero-wallpaper，同为 MIT）：
  - 壁纸图层方案——`#zotero-pane-stack`（Zotero 7+ 已 position:relative）最底层插入
    absolute 图层（z-index 0、pointer-events none、cover 铺图），兄弟内容层抬 z-index 1，
    `isolation: isolate` 为 backdrop-filter 提供采样上下文；
  - 玻璃面板——实测的 GLASS 选择器清单（#tabs-deck/#zotero-pane/virtualized-table 等
    自绘不透明背景的元素）transparent 化让壁纸透出；非选中行强制透明；
  - 毛玻璃——工具栏/侧栏 `backdrop-filter: blur(透明度/7 px)`；
  - 半透明调色——面板不透明度 = (100-opacity)%，工具栏减半保可读性，
    menupopup 保持不透明（XUL 弹窗是独立原生窗口，半透明会透出桌面）。
- **预置壁纸插画**：全部为本项目用 SVG 程序化生成的原创图案（樱吹雪/星海/紫夜月轮/
  薄荷气泡），未使用任何第三方图片素材，无版权风险；自定义壁纸由用户提供本地文件。

### 主题库与动态壁纸（0.17.0，ui-theme.js 重构）
- **主题模型**：主题 = 配色色板 + 壁纸 一体包（standard/anime/scenery/dynamic 四类 19 套），
  点击卡片一键切换（配色 + 壁纸 + 推荐可见度同时生效），pref 持久化重启自动恢复。
- **动态壁纸引擎**：SMIL 动画 SVG。关键技术事实——SVG 以 CSS background-image 引用时
  动画不执行（静态渲染），必须 DOMParser 解析后以内联 SVG DOM 插入壁纸层，SMIL
  （animate/animateTransform/animateMotion）才会运行；此为 svg-anim 引擎的实现依据。
- **视频壁纸**：用户本地 mp4/webm 等经 file:// URI 以 `<video autoplay loop muted
  playsinline>` 插入壁纸层（object-fit: cover）；文件仅路径引用不复制入库。
- **全部插画为程序化生成的原创 SVG**（19 套：樱吹雪 2.0/薄荷气泡/紫夜月轮 2.0/星海 2.0/
  绯红枫火/金盏朝日/远山墨色/极光之夜/暮光峡谷/雪原晨光 + 动态 5 套），
  零第三方图片素材，无版权风险。
