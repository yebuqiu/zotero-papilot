## 问题清单与修复

| # | 模块 | 问题 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | 设置面板（prefs.css） | 主题强制深色+系统浅色（或反向）时，pp 卡片与窗口背景割裂：深窗白卡/浅窗黑卡 | `--pp-` 变量只在 `prefers-color-scheme` 下切换，不跟随主题系统 | ui-theme 注入 CSS 时按主题色板派生整套 `--pp-` 变量，**直接命中 `.pp-root` 元素自身**（CSS 自定义属性按声明元素层叠，父级继承的 `!important` 打不过子元素自身声明——仿真实测确认后修正选择器） |
| 2 | 条目列表行 | 深色主题下 hover 几乎不可见 | hover 混合度仅 6% | 提高至 14%，hover 行文字强制主题 ink 色 |
| 3 | 期刊分区列（rank-column） | 用户报告"被覆盖" | 排查结论：badge 本身（彩底白字内联样式）四种组合下均可见（仿真验证）；真实遮挡场景为 ① 设置面板分区卡片割裂（问题 1）② 壁纸模式下面板透明叠加 | 问题 1 修复后设置面板分区卡恢复正常；badge 保持；被引量列深红改主题变量（见 #5） |
| 4 | AI 问答侧栏 / PDF 速览（ai-chat-pane / glance-pane） | 深色主题下灰色提示文字不可读 | 硬编码 `#666/#888` 深灰 | 改 `var(--fill-secondary/tertiary)`（随主题切换） |
| 5 | 被引量列（citation-column） | 高被引深红 `#c0392b` 在深色背景对比不足（~2.4:1） | 硬编码深红 | 改 `var(--accent-red)`（深色主题自动取亮红 #f85149） |
| 6 | 功能中心（hub.xhtml/hub.js） | 深色主题下浅灰卡片 `#fafafa`、深字 `#333` 等 10 处硬编码，窗口未纳入主题作用域 | 硬编码 + 作用域白名单缺失 | 全部改 CSS 变量；`window[windowtype='papilot:hub']` 纳入主题注入 |
| 7 | 小对话框（paste-check / refs-picker / tag-preview） | 白底容器 `#fff` + 灰字 `#666/#777/#999`，深色主题下割裂 | 硬编码 + 无 windowtype | 统一加 `windowtype="papilot:dialog"` 纳入作用域；硬编码改变量；对话框表单控件（textarea/input）主题化 |
| 8 | Zotero 原生元素 | menupopup hover、tooltip、标签选择器、item pane 字段标签在深色下可能吃硬编码浅色 | Z7 部分组件未变量化 | 主题 CSS 补 4 条保守补丁（变量值，不覆盖结构） |

## 不受影响模块（已确认正常）

- **工作台（workbench）**：有自治 wbTheme 体系（auto/light/dark + matchMedia 自适应），不纳入主题作用域，深浅自适应正常
- **划词浮窗（reader-popup）**：半透明中性色 `rgba(128,128,128,x)` + `color:inherit`，深浅自适应
- **PDF 阅读主题（pdf-theme）**：独立体系（叠色/反色），与界面主题解耦
- **分区 badge**：彩底白字内联样式，四种组合仿真均可见
