三步配好 Papilot 第 1 / 3 步 1 · 登录或注册 Papilot 账号 登录后可直接使用官方 AI 模型（按额度扣费，注册即赠送额度）。 已有账号直接登录；没有账号就在下面注册——不用跳浏览器。不想现在弄也可以跳过，之后在「设置 → 账号与会员」里补。 已登录： 邮箱 密码 登录 没有账号？立即注册 邮箱 昵称（可选） 密码（至少 8 位） 确认密码 注册后需到邮箱点验证链接激活（24 小时内有效）；站点未配置邮件服务时会直接激活。 密码只用于注册/登录请求，不会保存在本机。 注册并登录 已有账号？去登录 2 · 选择 AI 通道 全部 AI 功能（问答 / 翻译 / 打标 / 速递）都走「活动通道」。官方通道登录即用；也可以接自己的 OpenAI 兼容接口。 官方通道（推荐） 登录或注册账号即可使用，按 AI 额度扣费；模型随会员等级变化。 我自己的接口 任意 OpenAI 兼容 /v1 地址（DeepSeek / 智谱 / Ollama…），密钥只存本机。 接口地址（含 /v1） API Key 测试连接 选「稍后配置」不影响走完向导：之后在「设置 → AI 能力 → AI 模型通道」里配也行。 3 · 选择翻译引擎 划词翻译、全文对照、标题摘要共用这一套。AI 大模型质量最好（需要第 2 步可用）；免费引擎不需要任何配置。 AI 大模型（推荐） 走你的活动通道，术语表能生效，专业术语全文一致；通道不可用时会自动改用免费引擎。 免费引擎（Google / 必应） 零配置、免密钥，开箱即用；术语表不生效。 配置完成 下面是这次写入的结果；随时可以在「设置」里改。 稍后再说 打开设置 上一步 下一步 开始使用
